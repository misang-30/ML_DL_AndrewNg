## 1. 신경망의 구조
- 입력층 :원본 특성
- 은닉층 : 입력값을 조합하여 새로운 의미 있는 특성 생성
- 출력층 : 예측
- 함수를 직접 만들거나 아니면 가져다가 쓰는 예제가 있다.

## 2. 주요 함수
- dense : 한 레이어에서 계산해주는 함수
- sequential () : 파이프라인

| 텐서플로우 기준              |                                                                                  |
| --------------------- | -------------------------------------------------------------------------------- |
| **`W[:, j]` 슬라이싱**    | W 행렬에서 **j번째 뉴런에 해당하는 가중치 벡터**를 추출하는 파이썬/NumPy 문법<br>: 이거는 전체 행이고, j열만 추출하겠다는 것. |
| **`dense()` 함수**      | 이전 층의 출력(`a_in`)과 W,b를 입력받아 현재 층의 출력을 반환하는 기본 블록                                 |
| **`sequential()` 함수** | `dense()` 함수를 체인처럼 연결하여 최종 예측값 f(x)를 도출하는 전체 파이프라인                               |

## 3. 벡터화
- np.transpose(A) : 전치 행렬
- np.matmul(AT, W) : 행렬 곱셈
- Z = AT @ W : 행렬 곱셈

## 4. 모델 예제
``` python

import tensorflow as tf
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense

# 1. 모델 정의
model = Sequential([
    Dense(units=25, activation='relu'),
    Dense(units=15, activation='relu'),
    Dense(units=10, activation='softmax')  # 10개 클래스 출력을 위해 Softmax 적용
])

# 2. 컴파일 (손실 함수 지정)
model.compile(
    loss=tf.keras.losses.SparseCategoricalCrossentropy(),
    optimizer=tf.keras.optimizers.Adam(learning_rate=0.001)
)

# 3. 학습
model.fit(X, Y, epochs=10)

```

## 5. 손실 함수 Vs 비용 함수

| **구분** | **손실함수 (Loss Function)** | **비용함수 (Cost Function)**   |
| ------ | ------------------------ | -------------------------- |
| **대상** | **단 1개의 데이터**            | **전체 데이터셋 (또는 배치)**        |
| **의미** | 예제 하나에 대한 모델의 **오차**     | 전체 데이터의 손실(오차)을 **평균 낸 값** |
| **비유** | 시험에서 **1번 문제 하나 틀린 것**   | **전체 시험지 성적표 점수**          |


## 6.활성화 함수

### 1). 은닉층 필수 함수

- 1. ReLU  (은닉층의 디폴트)
- **수식:** $f(x) = \max(0, x)$
- **출력 범위:** $[0, \infty)$

- 2. Leaky ReLU
- **수식:** $f(x) = \max(\alpha x, x)$ _(보통 $\alpha = 0.01$)_
- **출력 범위:** $(-\infty, \infty)$

- 3.GELU

### 2). 출력층
- 1. sigmoid
- - **수식:** $\sigma(x) = \frac{1}{1 + e^{-x}}$
- **출력 범위:** $(0, 1)$

- 2.softmax
- - **수식:** $S(x_i) = \frac{e^{x_i}}{\sum e^{x_k}}$
- **출력 범위:** $(0, 1)$, **모든 클래스 확률의 합 = 1**
- 모든 출력 활성화 값이 서로 연결되어 동시에 계산되므로 다중 클래스 분류 모델에서는 이것을 사용한다. 서로 얽혀있기 때문.

- 3.Tanh
- **수식:** $\tanh(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}}$
- **출력 범위:** $(-1, 1)$

## 6. Layer

### 1). Dense Layer vs. Convolutional Layer

- **Dense Layer (완전 연결층)**:
    
    - 이전 층의 모든 활성화값(All Activations)을 다음 층의 각 노드로 연결하여 계산합니다.
        
    - 모델이 강력하지만, 입력 데이터의 크기가 커질수록 파라미터 수가 급격히 늘어납니다.
        
- **Convolutional Layer (합성곱 층)**:
    - 각 뉴런이 입력 데이터의 특정 국소 영역(Limited Region/Window)만 바라보고 특징을 추출합니다.
        
### 2). Convolutional Layer의 주요 장점
1. **계산 속도 향상 (Speed Up Computation)**:
    - 연결된 가중치(Parameters)의 수가 적어져 계산 연산량이 크게 줄어듭니다.
2. **필요 데이터량 감소 및 과적합 예방 (Less Training Data & Less Overfitting)**:
    - 이미지나 신호 데이터의 공간적/시간적 국소 특징(Local Patterns)에 집중하므로 적은 데이터로도 학습이 잘 되며, 과적합(Overfitting) 발생 가능성이 낮아집니다.

## 7. Back Propagation
### 1). 역전파는 왜 오른쪽 부터 하는가?
- 체인룰을 이용하면 금방 계산을 할 수 있기 때문.
- 왼쪽부터 하면 입력값 조금 변동시키고 중간 레이어 보고, 또 보고 하는 이런 과정을 너무 많이 해야한다.
### 2). Computation Graph
- **컴퓨터가 미분을 아주 쉽게 하기 위해 계산을 잘게 쪼개놓은 형태**라고 생각하시면 됩니다.
- 예를 들어, 작성해주셨던 수식 중 일부인 **$C = W \cdot X$** 와 **$A = C + B$** 과정은 아래처럼 그려집니다.

```
[ W = 2 ] ──┐
            ├──> ( × 곱셈 노드 ) ──> [ C = -4 ] ──┐
[ X = -2 ] ─┘                                     ├──> ( + 덧셈 노드 ) ──> [ A = 4 ]
                                    [ B = 8 ] ────┘
```

## 9. Bias(편향)와 Variance(분산)

### 1). 진단
-  언더피팅 ( High Bias)
	- 훈련 오차 높음
	- 검증 오차 높음
-  오버피팅 ( High Variance)
	- 훈련 오차 낮음
	- 검증 오차 높음
- 알맞음  
	- 훈련 오차 낮음
	- 검증 오차 낮음
### 2). 정규화
- **정규화(Regularization) 목적:** 모델의 가중치 w가 너무 커지지 않도록 억제하여 오버피팅을 방지함.
- 훈련 오차
	- λ가 증가할수록 가중치 w를 줄이는 데 집중하므로, 훈련 데이터를 맞추는 능력은 떨어져 우상향(지속적 증가)합니다.
- 검증 오차
	- λ가 너무 작을 때(Left): 오버피팅(High Variance)으로 인해 Jcv가 높음.
        
    - λ가 적절할 때(Center): **Jcv가 가장 낮은 최적 지점** 형성.
        
    - λ가 너무 클 때(Right): 언더피팅(High Bias)으로 인해 Jcv가 다시 높아짐.

### 3). 베이스 라인 
- Jtrain(훈련 오차)이 10%가 나왔을 때, 이 값만 보고 바로 "훈련 오차가 높으니 High Bias(언더피팅)이다"라고 결론을 내리기 어렵습니다.
-  **해결책:** 모델이 현실적으로 달성할 수 있는 목표 오차 수준인 베이스라인 성능(Baseline Level of Performance)을 설정하고, 이와 비교하여 진단해야 합니다.
#### (1). 성능 설정법
- 1.인간 수준의 성능
- 2.기존/경쟁 알고리즘 서능
- 3.이전 경험에 기반한 추정


### 4). 학습 곡선
#### (1). High Bias (모델이 너무 단순)
-  Jtrain과 Jcv 모두 높고, 거의 수평으로 정체(Plateau)합니다.
        
-  데이터가 늘어나도 단순한 모델(예: 1차 직선)의 한계 때문에 성능이 개선되지 않습니다.
> 해결책
> 1.추가 특성 도입
> 2.다항식 특성 추가
> 3.정규화 파라미터 감소


### (2). High Variance (모델이 너무 복잡)
- - Jtrain은 매우 낮고, Jcv는 상대적으로 매우 높아 두 곡선 사이에 큰 격차(Large Gap)가 존재합니다.
        
- 데이터 크기(m)를 계속 늘려 x축 오른쪽으로 확장(Extrapolate)하면, Jcv가 지속적으로 하강하며 Jtrain 및 Baseline에 가까워집니다.

> 해결책 
> 1.더 많은 데이터 수집
> 2.특성 개수 줄이기
> 3.정규화 파라미터 증가

## 11. 전이 학습
- 전이 학습은 **대규모 데이터셋으로 미리 학습된 모델(Pre-trained Model)의 지식(가중치/파라미터)을 가져와, 데이터가 적은 나의 애플리케이션에 재활용하여 성능을 크게 끌어올리는 기법**입니다.


```
<전이학습 2단계 프로세스>
1단계: 사전 학습 (Pre-training)]
 대규모 데이터 (예: 100만 개 이미지, 1,000개 클래스)
 ──► 신경망 전체 학습 ──► 파라미터 (W1, b1 ~ W5, b5) 추출

                           │
                           ▼
[2단계: 미세 조정 (Fine-tuning)]
 내 데이터셋 (예: 손글씨 0~9 인식, 10개 클래스)
 ──► 마지막 출력층 변경 (1,000개 ──► 10개)
 ──► 가중치 재활용 및 재학습 진행
 
```

### (1). 미세 조정
- 기존 모델에서 **마지막 출력층만 제거**하고, 내가 풀고자 하는 문제(예: 0~9 손글씨 분류 → 출력 유닛 10개)에 맞게 **새로운 출력층(W[5],b[5])을 붙입니다.**
    
- 사전 학습된 파라미터를 초기값(Starting Point)으로 삼아 내 데이터셋으로 재학습시킵니다.
### 2). 미세 조정(Fine-tuning)을 위한 2가지 옵션

| **구분**    | **옵션 1: 마지막 층만 학습 (Train Output Layer Only)**                | **옵션 2: 전체 층 학습 (Train All Layers)**             |
| --------- | ------------------------------------------------------------ | ------------------------------------------------ |
| **작동 방식** | 앞단 레이어(W[1]∼W[4])는 **고정(Freeze)**하고, 새롭게 추가한 **마지막 출력층만 학습** | 사전 학습된 값으로 전체 레이어를 초기화한 뒤, **모든 레이어의 가중치를 업데이트** |
| **적용 조건** | 내가 가진 데이터셋이 **매우 적을 때**                                      | 내가 가진 데이터셋이 **어느 정도 존재할 때**                      |

## 12. Skewed Datasets
- 불균형 데이터셋을 위한 에러 평가 지표
- 정확도(Accuracy) 지표만 쓰는 것에 한계가 있다.
- 정밀도(Precision)와 재현율(Recall)을 같이 쓴다.
- 불균형 데이터셋에서는 정확도 대신 **정밀도**와 **재현율**을 함께 측정해야 합니다.

|                            | 실제 양성 (Actual Positive, y=1) | 실제 음성 (Actual Negative, y=0)                                |
| -------------------------- | ---------------------------- | ----------------------------------------------------------- |
| 예측 양성  <br>(Predicted y=1) | **True Positive (TP)**  <br> | False Positive (FP)  <br>• 실제 음성을 **양성으로 틀리게 예측** _(거짓 양성)_ |
| 예측 음성  <br>(Predicted y=0) | False Negative (FN)          | True Negative (TN)  <br>                                    |

#### (1) 정밀도 (Precision)

- **질문:** _"모델이 양성($y=1$)이라고 예측한 환자들 중, 실제로 병을 가진 비율은 얼마인가?"_
- **공식:**    
    Precision=True Positives (TP) / Predicted Positives (TP + FP)
- **의미:** 모델이 양성이라고 진단했을 때의 **신뢰도/정확성**을 의미합니다.
    

#### (2) 재현율 (Recall)

- **질문:** _"실제 병을 가진 전체 환자들 중, 모델이 제대로 찾아낸(진단한) 비율은 얼마인가?"_    
- **공식:**
    Recall=True Positives (TP) / Actual Positives (TP + FN)
- **의미:** Actual Positive 중 실제 양성을 얼마나 잘 감지/포착(Recall)해냈는지를 의미합니다.

### (3) F1 Score
- Precision과 Recal 값이 따로 놀면 어떤 모델이 더 좋은지 한눈에 보기는 힘들다.
- 또한, 단순 평균으로 위 2개의 값을 다루므로 판단이 더 어렵다.
- 그래서 F1 Score를 사용한다.
- 조화 평균은 두 값 중 더 작은 값에 끌려가는 성질이 있다.
- Precision과 Recall 중 더 낮은 수치에 훨씬 더 가중치를 두는 수식이다. (조화 평균)
- F1 Score 계산 공식 : F1=2×(P×R)/(P+R)
- 두 지표 중 하나라도 0에 가까워지면 F1 Score는 0으로 폭락한다.
- 0~ 1까지의 값을 가지면, 클 수록 좋다.
-
