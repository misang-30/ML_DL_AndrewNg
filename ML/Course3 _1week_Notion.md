# 비지도 학습을 다룬다. 
## 1. K-평균 클러스터링 (K-means Clustering)

### 1). K-means 개요 및 동작 알고리즘

#### (1). 비지도 학습에서의 군집화 (Clustering)

- 정답 라벨($y$)이 없는 무라벨 데이터에서 데이터 간의 거리를 기반으로 유사한 패턴끼리 묶어주는 대표적인 비지도 학습 기법입니다.
    

#### (2). 알고리즘 4단계 절차

- **1단계 (초기화):** 클러스터 개수 $K$를 설정하고, 공간 상에 $K$개의 중심점(Centroid, $\mu_1, \dots, \mu_K$)을 무작위로 위치시킵니다.
    
- **2단계 (데이터 할당):** 모든 데이터 포인트에서 각 중심점까지의 거리를 계산하여 가장 가까운 중심점의 클러스터로 할당합니다. 이때 비용 함수 계산.
    
- **3단계 (중심점 이동):** 각 클러스터에 할당된 데이터들의 평균 좌표를 구하여 중심점을 해당 위치로 이동시킵니다.
    
- **4단계 (수렴 및 반복):** 중심점의 위치 변화가 없을 때까지 2단계와 3단계를 지속해서 반복합니다.
- 여러 번 반복하고 그 중에서 비용 함수가 가장 작은 것 고르면 된다.
- 
### 2). K-means 비용 함수와 최적화

#### (1). 비용 함수 (Cost Function / Distortion Function)

- 각 데이터 포인트와 속한 클러스터 중심점 간의 제곱 거리의 평균을 의미하며, 이를 최소화하는 것이 목적입니다.
    
- $$J(c^{(1)}, \dots, c^{(m)}, \mu_1, \dots, \mu_K) = \frac{1}{m} \sum_{i=1}^{m} \vert{}\vert{}x^{(i)} - \mu_{c^{(i)}}\vert{}\vert{}^2$$
    

#### (2). 국소 최적점(Local Optima) 탈출법

- 무작위 초기화에 따라 성능이 낮아지는 국소 최적점에 갇힐 수 있습니다.
    
- 이를 해결하기 위해 **무작위 초기화를 50~1000번 반복 실행**한 후, 비용 함수 $J$가 가장 낮게 나온 모델을 최종 선택합니다.
    

#### (3). 최적의 클러스터 개수($K$) 선택법

- **엘보 기법 (Elbow Method):** $K$를 늘려가며 비용 $J$의 감소폭을 그래프로 그릴 때, 감소세가 완만해지는 "팔꿈치" 지점을 선택합니다.
    
- **다운스트림 목적 고려 (추천):** 엘보 지점이 불명확한 경우가 많으므로, 비즈니스 목적(예: 의류 사이즈 S/M/L 구분 등)에 따라 $K$를 결정하는 것이 좋습니다.
    

## 2. 이상 탐지 (Anomaly Detection)

### 1). 이상 탐지의 개념 및 수학적 모델링

#### (1). 이상 탐지의 기본 개념

- 정상 데이터의 패턴 분포를 학습한 후, 새로운 데이터가 들어왔을 때 기존 패턴에서 크게 벗어나는 비정상(Anomaly) 데이터를 찾아냅니다.
    

#### (2). 가우시안 정규분포 (Gaussian Distribution) 활용

- 각 특성(Feature)이 정규분포를 따른다고 가정하고 확률 밀도를 구합니다.
    
- $$p(x; \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left( -\frac{(x - \mu)^2}{2\sigma^2} \right)$$
    
- 평균($\mu$)과 분산($\sigma^2$)은 정상 데이터를 통해 추정합니다.
    

#### (3). 이상 여부 판정 절차

- 모든 특성의 확률을 곱하여 전체 확률 밀도 $p(x) = \prod_{j=1}^{n} p(x_j; \mu_j, \sigma_j^2)$를 구합니다.
    
- 계산된 $p(x)$가 임계값 $\epsilon$보다 작으면($p(x) < \epsilon$) 비정상 데이터로 판단합니다.
    

### 2). 이상 탐지 vs 지도 학습 비교

#### (1). 양성(Positive) 데이터의 수

- **이상 탐지:** 비정상 데이터(Positive)가 매우 적음 (0~20개 내외).
    
- **지도 학습:** 양성과 음성 데이터 모두 충분히 많음.
    

#### (2). 이상 패턴의 유형 및 예측 가능성

- **이상 탐지:** 데이터에 나타나지 않은 **새로운 형태의 이상 징후**가 발생할 가능성이 큼.
    
- **지도 학습:** 미래에 발생할 이상 패턴이 이미 학습 데이터에 포함되어 있고 정형화되어 있음.
    

#### (3). 대표적 적용 사례

- **이상 탐지:** 카드 부정 사용 감지, 공장 불량품 검출, 서버 장애 모니터링.
    
- **지도 학습:** 스팸 메일 분류, 암 진단, 날씨 예측.
    

### 3). 이상 탐지 성능 향상 기법

#### (1). 평가 지표 설정

- 데이터 불균형이 극심하므로 정확도(Accuracy) 대신 검증 세트(Validation Set) 기반의 **F1-Score, Precision, Recall**을 이용해 임계값 $\epsilon$을 조정합니다.
    

#### (2). 데이터 분포의 정규화 변환

- 특성 데이터가 한쪽으로 쏠린(Skewed) 경우 $\log(x)$, $\log(x+c)$, $\sqrt{x}$ 등을 적용하여 정규분포 형태로 변환 후 모델에 입력합니다.
    

#### (3). 새로운 특성(Feature) 생성

- 정상과 비정상이 잘 구분되지 않을 경우, 기존 특성들의 관계를 조합(예: $\frac{\text{CPU 사용량}}{\text{네트워크 트래픽}}$)하여 판별력이 뛰어난 특성을 직접 만들어 사용합니다.
