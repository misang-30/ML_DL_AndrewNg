3주차의 핵심 주제는 **하이퍼파라미터 튜닝(Hyperparameter Tuning), 배치 정규화(Batch Normalization),  입니다.

## 1. 하이퍼파라미터 튜닝 (Hyperparameter Tuning)

### 1). 중요도 순위

1. **1순위 (가장 중요):** 학습률 ($\alpha$)
    
2. **2순위 (중요):** Momentum $\beta$, 모멘텀/Adam 관련 파라미터, 은닉층 노드 수, 미니배치 크기
    
3. **3순위 (상대적 낮음):** 레이어 수, Decay rate (학습률 감쇠)
    
4. **동결 (수정X):** Adam 알고리즘의 $\beta_1=0.9, \beta_2=0.999, \varepsilon=10^{-8}$
    

### 2). 튜닝 방식: Grid Search vs Random Search

- 1.**Grid Search (격자 탐색) 비추천:** 하이퍼파라미터의 중요도가 서로 다르기 때문에 격자 형태로 탐색하면 비효율적입니다.
- 파라미터 B가 중요도가 없다면 9번을 해도 3번만 한 것과 다르지 않아진다.
```
[파라미터 B]
    ▲
    │  (1)───(2)───(3)
    │   │     │     │
    │  (4)───(5)───(6)
    │   │     │     │
    │  (7)───(8)───(9)
    └──────────────────► [파라미터 A]
```

- 2.**Random Search (랜덤 탐색) 추천:** 중요도가 높은 하이퍼파라미터의 다양한 값을 골고루 탐색할 수 있습니다.
```
[파라미터 B]
    ▲
    │      * (2)       * (5)
    │   * (1)     * (4)     * (8)
    │       * (3)       * (7)
    │    * (6)       * (9)
    └─────────────────────────► [파라미터 A]
```
- 3.**Coarse to Fine (정밀 탐색):** 전체 범위에서 랜덤 탐색 후, 성능이 잘 나오는 유망한 구역을 집중적으로 다시 랜덤 탐색합니다.
- 돋보기로 보물찾기를 하는 것과 같습니다.

	1. **Coarse Search (성기게 찾기):**
	    전체 영역(예: $0.0001 \sim 1.0$)에 넓게 랜덤 점을 찍어봅니다.
	2. **유망한 구역 발견:**
	    실험해보니 $0.001 \sim 0.01$ 사이에서 유독 모델 성능이 좋게 찍히는 것을 확인합니다.
	3. **Fine Search (정밀하게 찾기):**
	    이제 돋보기를 대듯 범위 공간을 $0.001 \sim 0.01$ 로 좁힌 뒤, **그 안에서만 다시 집중적으로 랜덤 탐색**을 실시합니다.

### 3). 적절한 스케일(Scale) 선택

- 변수의 특성에 따라 탐색 스케일을 다르게 설정해야 합니다.
- 하이퍼파라미터를 랜덤 탐색 할떄, 숫자의 범위를 어떻게 나누어 뽑을 것인가에 대한 문제이다.
- **은닉 노드 수 / 레이어 수:** 선형 스케일(Linear scale) 탐색 (예: 50~100)
	- 숫자의 크기와 상관없이 모든 수치 간격의 중요도가 일정할 때 사용한다.
    
- **학습률 ($\alpha$):** 로그 스케일(Log scale) 탐색

    - 학습률처럼 **'덧셈(+)'이 아니라 '곱셈($\times$10, $\times 0.1$)' 단위로 영향력이 바뀌는 변수**에 사용합니다.
    - 자릿수(지수)를 균등하게 탐색하기 위해 지수 $r$을 먼저 뽑고, $10^r$을 취합니다.

	1. **지수로 변환:**
	    - $0.0001 = 10^{-4} \rightarrow a = -4$
	    - $1.0 = 10^0 \rightarrow b = 0$
        
	2. **지수 $r$을 균등 추출:**
	    - $-4$와 $0$ 사이에서 무작위 실수 $r$을 뽑습니다. (예: $-3.2, -1.5, -0.2$ 등)
    
	3. **학습률 계산:**
	    - $\alpha = 10^r$ 로 지정합니다.
	- 이렇게 하면 $0.0001 \sim 0.001$, $0.001 \sim 0.01$, $0.01 \sim 0.1$, $0.1 \sim 1$ 각 구간에 **동일하게 25%씩 탐색 기회**가 주어집니다.

- **$\beta$ (Hyperparameter for Exponentially Weighted Average):**
    - $0.9 \sim 0.999$ 탐색 시 $1-\beta$에 대해 로그 스케일 적용 ($0.001 \sim 0.1$ 범위 탐색)
    - $\beta$는 지수 가중 이동 평균에서 **과거 데이터를 얼마나 반영할지** 정하는 지수입니다.
		- $\beta = 0.9$이면 약 **10일** 동안의 평균 ($\frac{1}{1 - 0.9} = 10$)
		- $\beta = 0.99$이면 약 **100일** 동안의 평균 ($\frac{1}{1 - 0.99} = 100$)
		- $\beta = 0.999$이면 약 **1000일** 동안의 평균 ($\frac{1}{1 - 0.999} = 1000$)
    
	-  Q. 왜 $1-\beta$로 뒤집어서 탐색할까?
		- $\beta$가 $0.90 \rightarrow 0.99$로 $0.09$ 만큼 살짝 커질 때는 영향력이 **10일 $\rightarrow$ 100일**로 90일이나 늘어납니다. 반면 $0.90 \rightarrow 0.91$로 바뀔 때는 영향력이 거의 차이 나지 않습니다.
		- 즉, **$\beta$가 $1$에 가까워질수록 아주 미세한 변화에도 모델의 동작이 크게 달라집니다.**

### 4). 모델 훈련 방법론

- **Panda 방식 (Babysitting One Model):** 컴퓨팅 자원이 부족할 때, 하나의 모델을 매일 모니터링하며 하이퍼파라미터를 수동으로 조금씩 조정
    
- **Caviar 방식 (Training Many Models in Parallel):** 자원이 충분할 때, 서로 다른 하이퍼파라미터를 가진 여러 모델을 동시에 훈련

## 2. 배치 정규화 (Batch Normalization)

- 입력 데이터 $X$를 정규화(Normalization)하여 학습 속도를 높이듯, **은닉층의 활성화 전 값 $Z^{[l]}$도 정규화**하는 기법입니다.

### 1). 계산 단계 (특정 은닉층의 미니배치 기준)

1. **평균 계산:** $\mu = \frac{1}{m} \sum_i Z^{(i)}$
2. **분산 계산:** $\sigma^2 = \frac{1}{m} \sum_i (Z^{(i)} - \mu)^2$
3. **표준화:** $Z_{\text{norm}}^{(i)} = \frac{Z^{(i)} - \mu}{\sqrt{\sigma^2 + \varepsilon}}$
4. **스케일 및 이동(Scale and Shift):** $\tilde{Z}^{(i)} = \gamma Z_{\text{norm}}^{(i)} + \beta_{\text{BN}}$
    - $\gamma, \beta_{\text{BN}}$은 역전파를 통해 학습되는 파라미터입니다.
    - 네트워크가 필요한 경우 평균 0, 분산 1이 아닌 최적의 분포로 스스로 재조정할 수 있게 해줍니다.
> **주의:** Batch Norm 적용 시, 이전 단계의 편향 $b^{[l]}$은 평균을 빼는 과정에서 상쇄되므로 제거($b^{[l]} = 0$)해도 무방합니다 ($\beta_{\text{BN}}$이 그 역할을 대신함).

### 2). Batch Norm이 잘 작동하는 이유

1. **은닉층 입력의 정규화:** 학습 속도를 획기적으로 향상시킵니다.
    
2. **Covariate Shift 완화:** 앞선 레이어의 파라미터 변화로 인해 뒤쪽 레이어의 입력 분포가 흔들리는 현상(Covariate Shift)을 줄여주어, 각 레이어가 독립적으로 안정되게 학습합니다.
    
3. **약한 정규화(Regularization) 효과:** 미니배치 단위의 평균/분산 소음(Noise)이 추가되어 약간의 오버피팅 방지 효과가 있습니다.
    
### 3). 테스트(Inference) 시 동작

테스트 시에는 단 1개의 데이터만 들어올 수 있으므로 미니배치 평균/분산을 구할 수 없습니다. 따라서 **훈련 과정에서 지수 가중 이동 평균(EWMA)으로 미리 계산해 둔 $\mu, \sigma^2$값**을 사용하여 정규화를 수행합니다.
