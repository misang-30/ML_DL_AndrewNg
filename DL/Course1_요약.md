## 1. 벡터화

- 코드에 명시적인 for루프를 제거하고 벡터 / 행렬 연산을 직접 수행하는 기법
- Numpy의 np.dot() 함수를 사용하면 된다.
### np.dot()
- np.dot (A,B)함수는 A의 열과 B의 행의 크기가 같아야만 한다.
- 벡터와 벡터 간의 곱에서는 내적값이 나온다.
``` python
import numpy as np

v = np.array([1, 2, 3])
w = np.array([4, 5, 6])

np.dot(v, w)
# 결과값 32
 
```

### Numpy의 벡터 
- 벡터의 shape은 (n,)이다. (Numpy에서 1차원 배열은 행벡터인지 열벡터인지 구분하지 않는다. )
```python
v = np.array([1, 2, 3]) 
# v.T.shape와 v.shape 는 (3,)으로 동일 하다. 
```
- 따라서 "행렬과 벡터" 연산시 벡터가 행벡터인지 열벡터인지 신경쓸 필요가 없다.
``` python
m= np.array([[1, 2, 3],

[4, 5, 6]])

  

x = np.array([1, 2, 3])

#print(np.dot(m, x.T).shape)
#print(np.dot(m, x.T).T.shape) 서로 동일한 값, 같은 shape(2,)

```

- Numpy에서 1차원 벡터를 사용할 때는 방향을 신경 안 써도 된다.
- 2차원 배열로 다루면 방향을 정확히 맞추어야 한다.

### 1차원 배열 Vs 다차원 배열 
- 차원은 우선 대괄호 개수로 판별
- "np.ndim"함수나 "np.shape" 함수로 판별도 있다.
- 1차원 배열은 전치를 해도 shape이 똑같으나, 다차원 배열은 아니다. 
- 행렬 곱셉 전용 연산자 @를 쓸 수 있느냐 없느냐로도 나뉜다.
- @ 와 np.dot()은 차이가 있긴 하나, 2차원에서는 거의 같다.
- @는 파이썬 자체 연산자 이다. (행렬끼리만 가능)
``` [!Notice]
NumPy 커뮤니티와 공식 문서에서는 “행렬 곱이라면 `@` 또는 `np.matmul()`을 쓰는 것이 더 명확하다”는 방향으로 바뀌었다.
그런데 코드를 읽는 사람 입장에서는dims=True를 붙이지 않으면 축이 사라지면서 자동으로 Rank 1 Array(1차원 배열)로 변해버리는 현상이 일어납니다. `A @ B`를 보면 “아, 행렬 곱이구나”를 즉시 알 수 있다. 반면 `np.dot(A, B)`는 벡터 내적인지 행렬 곱인지 잠깐 shape를 확인해야 한다.

```

| 구분         | `@`         | `np.dot()`       |
| ---------- | ----------- | ---------------- |
| 목적         | 행렬 곱        | 내적/행렬곱 등 여러 의미   |
| 도입         | Python 3.5+ | NumPy 함수         |
| 2D 행렬 × 행렬 | 같음          | 같음               |
| 행렬 × 벡터    | 같음          | 같음               |
| 벡터 × 벡터    | 내적          | 내적               |
| 3차원 이상 배열  | 배치 행렬곱      | 축 기준 내적 (다르게 동작) |
| 가독성        | 좋음          | 보통               |
- 결론부터 말하면 행렬 연산은 `@`를 기본으로 생각하면 된다.

|상황|추천|
|---|---|
|행렬 × 행렬|`A @ B`|
|행렬 × 벡터|`A @ x`|
|벡터 × 행렬|`x @ A`|
|벡터 · 벡터(내적)|`x @ y`|
|3차원 이상 배치 행렬곱|`A @ B` 또는 `np.matmul(A, B)`|
|옛 NumPy 코드 / 함수형 스타일|`np.dot()`|

## 2. 브로드 캐스팅
-  NumPy에서 모양(Shape)이 서로 다른 배열(Array) 간에 산술 연산을 수행할 때, 차원을 자동으로 확장하여 동일한 크기로 맞춘 후 요소별(element-wise) 연산을 가능하게 해주는 기술입니다.
- 아래 3가지 패턴이 있다. 
### 1). (m,n) 행렬과 (1,n) 행렬의 연산
- (1,n) 행렬을 아래(수직) 방향으로 m번 복사하여 (m,n) 크기로 확장한 후 요소별 연산을 수행합니다.
### 2). (m,n) 행렬과 (m,1) 행렬의 연산
- (m,1) 행렬을 옆(수평) 방향으로 n번 복사하여 (m,n) 크기로 확장한 후 요소별 연산을 수행합니다.
### 3). (m,1) 벡터와 스칼라(실수)의 연산
- 단일 스칼라(1x1) 값을 m번 복사하여 (m,1) 벡터로 확장한 후 계산합니다. (로지스틱 회귀의 +b 연산 방식)


``` python
import numpy as np

# 3x4 행렬 (행: 탄수화물, 단백질, 지방 / 열: 사과, 소고기, 계란, 감자)
A = np.array([[56.0, 0.0, 4.4, 68.0],
              [1.2, 104.0, 52.0, 8.0],
              [1.8, 135.0, 99.0, 0.9]])

# 1. 열 방향(수직) 합계 계산 (axis=0) -> 결과: (1, 4) 행렬
cal = A.sum(axis=0)

# 2. 브로드캐스팅을 활용한 비율(%) 계산
percentage = 100 * (A / cal.reshape(1, 4))
```

### 4). keepdims = True 활용

- `np.sum()`이나 `np.mean()` 같은 축(axis) 축소 연산을 할 때, `keepdims=True`를 붙이지 않으면 축이 사라지면서 **자동으로 Rank 1 Array(1차원 배열)로 변해버리는 현상**이 일어납니다.
``` python
import numpy as np 

A = np.random.randn(3, 4) # (3, 4) 행렬 
# [keepdims 미사용] -> 축이 사라져 (3,) 형태의 Rank 1 Array로 변함! 
s1 = np.sum(A, axis=1) # s1.shape -> (3,) 
# [keepdims=True 사용] -> 원래의 2차원 형태 (3, 1) 유지! 
s2 = np.sum(A, axis=1, keepdims=True) # s2.shape -> (3, 1)
```

## 1. 레이어 차원 - 버그 주의
- 행렬 곱셈이 성립하려면 **앞 행렬의 열 개수와 뒤 행렬의 행 개수가 반드시 같아야 합니다.**

$$(A \times \mathbf{B}) \times (\mathbf{B} \times C) = (A \times C)$$

- 신경망에서 가중치 $W$는 "이전 층의 입력 개수($n_{in}$)를 받아 현재 층의 출력 개수($n_{out}$)로 변환해 주는 공장"입니다.

- **$W$의 행렬 차원 공식:** $(\text{현재 층 노드 수 } n_{out} \times \text{이전 층 노드 수 } n_{in})$
- **실제 계산 과정 (1개 데이터 기준):**
    
    $$Z^{[1]} = \underbrace{W^{[1]}}_{(4 \times 3)} \cdot \underbrace{X}_{(3 \times 1)} + \underbrace{b^{[1]}}_{(4 \times 1)} = \underbrace{Z^{[1]}}_{(4 \times 1)}$$
    
    - 입력 데이터 $X$에 특성(Feature)이 3개 있고, 은닉층 노드가 4개라면?
    - $W^{[1]}$은 $(4 \times 3)$ 크기여야 $(3 \times 1)$ 크기의 입력과 곱해져 최종적으로 노드 개수인 $(4 \times 1)$ 형태의 결과를 만들어냅니다.
	- W의 4는 은닉층 노드 개수 4개.

## 2. 활성화 함수 선택 기준

- **은닉층 (Hidden Layer)**: **ReLU** ($a = \max(0, z)$) 사용이 기본 표준.
    - _이유:_ $z > 0$ 영역에서 기울기가 $1$로 유지되어 기울기 소멸(Vanishing Gradient)을 방지하고 학습 속도가 빠름.
        
- **출력층 (Output Layer)**:
    - **이진 분류**: **Sigmoid** ($0 \sim 1$ 확률 출력)
    - **회귀 문제**: **Linear** ($g(z) = z$) 또는 **ReLU**
        
- **은닉층 비선형성 필수 이유**: 은닉층에 비선형 활성화 함수가 없으면 ($g(z)=z$), 아무리 층을 깊게 쌓아도 단일 선형 회귀/로지스틱 회귀 모델과 수학적으로 완전히 동일해집니다 ($W' = W^{[2]}W^{[1]}$).

### 1). W 가중치 행렬
가중치 행렬은 노드 단 하나마다 따로 존재하는 것이 아니라, 한 레이어 전체를 하나의 행렬로 통째로 묶어서 표현한 것이다.
$$W^{[1]} = \begin{bmatrix} \text{--- 1번 노드의 가중치들 ---} \\ \text{--- 2번 노드의 가중치들 ---} \\ \text{--- 3번 노드의 가중치들 ---} \\ \text{--- 4번 노드의 가중치들 ---} \end{bmatrix} = \begin{bmatrix} w_{11} & w_{12} & w_{13} \\ w_{21} & w_{22} & w_{23} \\ w_{31} & w_{32} & w_{33} \\ w_{41} & w_{42} & w_{43} \end{bmatrix}_{(4 \times 3)}$$


### 2).  X 입력 데이터 행렬
#### (1). 데이터가 1개일 때: 열벡터 (Column Vector)

학습 데이터 1개만 생각할 때는 **$3 \times 1$ 크기의 세로 방향 벡터**입니다. (수학적으로 벡터는 행이 여러 개이고 열이 1개인 '특별한 행렬'입니다.)

$$x = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} \quad (3 \times 1)$$

#### (2). 데이터가 $m$개일 때: 대문자 행렬 $X$

데이터 $m$개를 한 번에 처리(벡터화)하기 위해, 1개짜리 열벡터들을 **가로(열) 방향으로 옆으로 쭉 쌓아서** 만들어낸 진짜 $3 \times m$ 크기의 대문자 행렬 $X$가 됩니다.

$$X = \begin{bmatrix} \vert & \vert & & \vert \\ x^{(1)} & x^{(2)} & \dots & x^{(m)} \\ \vert & \vert & & \vert \end{bmatrix} \quad (3 \times m)$$




## 3. 정방향 연산 & 역전파 연산

### 1). 정방향 연산 : 예측값 만들기

- 입력 데이터($X$)가 왼쪽에서 오른쪽으로 이동하며 예측값($\hat{y}$)을 만드는 과정입니다. 각 레이어는 딱 2단계(선형 계산 $\rightarrow$ 비선형 변환)만 반복합니다.

| **단계**            | **연산 식**                             | **하는 일 (직관적 의미)**                          |
| ----------------- | ------------------------------------ | ------------------------------------------ |
| **Layer 1 (은닉층)** | $Z^{[1]} = W^{[1]}X + b^{[1]}$       | 입력값에 가중치와 편향을 곱해 1차 합산                     |
|                   | $A^{[1]} = \text{ReLU}(Z^{[1]})$     | 비선형 활성화 함수를 통해 신호 강조/억제                    |
| **Layer 2 (출력층)** | $Z^{[2]} = W^{[2]}A^{[1]} + b^{[2]}$ | 은닉층의 출력($A^{[1]}$)을 입력으로 받아 다시 합산          |
|                   | $A^{[2]} = \text{Sigmoid}(Z^{[2]})$  | 최종 출력을 $0 \sim 1$ 사이의 확률 값($\hat{y}$)으로 변환 |

### 2). 역방향 연산  (여기 부분이 문제)

- 정방향에서 구한 예측값($\hat{y}$)과 실제 정답($Y$)을 비교해 오차(Loss)를 구한 뒤, 오른쪽에서 왼쪽(출력층 $\rightarrow$ 입력층)으로 가며 "이 오차에 누구 지분이 가장 큰가?"를 계산합니다.

- 1. 출력층 오차 확인 ($dZ^{[2]}$)
    $$dZ^{[2]} = A^{[2]} - Y$$
    - 예측값($\hat{y}$)에서 실제 정답($Y$)을 빼서 "얼마나 틀렸는지" 오차를 직접 계산합니다.
    
- 2. **출력층 가중치 수정량 계산 ($dW^{[2]}$):**
    $$dW^{[2]} = dZ^{[2]} \cdot (A^{[1]})^T$$
    - 출력층 오차($dZ^{[2]}$)에 은닉층 신호($A^{[1]}$)를 곱해 $W^{[2]}$를 어느 방향으로 고칠지 정합니다.
    
- 3. **은닉층으로 오차 전파 ($dZ^{[1]}$):**
    $$dZ^{[1]} = (W^{[2]})^T dZ^{[2]} \odot g^{[1]'}(Z^{[1]})$$
    - 출력층의 오차($dZ^{[2]}$)를 $W^{[2]}$를 거꾸로 타고 넘겨 은닉층 노드들이 가져야 할 오차 지분을 계산합니다.
    
- 4. **은닉층 가중치 수정량 계산 ($dW^{[1]}$):**
    $$dW^{[1]} = dZ^{[1]} \cdot X^T$$
    - 은닉층 오차($dZ^{[1]}$)를 바탕으로 첫 번째 가중치 $W^{[1]}$의 수정량을 구합니다.
- 이렇게 구한 $dW, db$ 만큼 경사하강법($W := W - \alpha \cdot dW$)을 통해 가중치를 조금씩 수정합니다.

## 4. 가중치 초기화
### 1). W = 0 초기화 절대 금지(대칭성 문제)

- 모든 가중치를 0으로 설정하면 은닉층의 모든 노드가 동일한 값 계산된다.
- 역전파 시 모든 노드가 동일하게 업데이트 된다. 따라서 노드를 여러 개 만든 의미가 상실된다
### 2). 올바른 초기화
- W를 작은 무작위 난수로 초기화 하라. ( np.random.randn() * 0.01)
- b : 0으로 초기화해도 무방
- 0.01을 곱하는 이유 : W가 너무 크면 z 값이 극단적으로 커져 Sigmoid/tanh 함수에서 기울기가 0에 가까워지는 포화 현상이 발생하여 학습이 멈춘다.

## 1. 깊은 네트워크를 쓰는 이유
- **계층적 특징 표현 (Hierarchical Representation):** low-level(선, 에지) $\rightarrow$ mid-level(눈, 코, 음소) $\rightarrow$ high-level(얼굴 전체, 단어) 순으로 복잡한 개념을 단계를 거쳐 단단하게 학습.
    
- **회로 이론적 효율성:** 얕고 거대한 네트워크는 지수적($O(2^n)$)으로 많은 뉴런이 필요하지만, 깊은 네트워크는 훨씬 적은 뉴런($O(\log n)$)으로 복잡한 함수 구현 가능.
