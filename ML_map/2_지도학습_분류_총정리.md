
## 1. Logistic Regression
- 선형 회귀의 출력값을 **시그모이드 함수**에 통과시켜 $0$과 $1$ 사이의 확률값으로 변환한 뒤, 이를 바탕으로 데이터가 특정 클래스에 속할지 **분류(Classification)**하는 모델.
#### 0) 개요 및 차이점

- 선형 회귀는 연속적인 값($\mathbb{R}$)을 예측하지만, 로지스틱 회귀는 **이진 분류(0 또는 1)** 문제를 해결합니다.
    
- 선형 방정식 $z = \mathbf{w}^T x + b$의 결과를 확률값으로 바꾸기 위해 활성화 함수(Activation Function)인 시그모이드 함수 $\sigma(z)$를 사용합니다.
    

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

#### 1) 가설 함수 (Hypothesis Function)

- 선형 회귀식에 시그모이드 함수를 적용하여 1일 확률($P(y=1\vert{}x)$)을 출력합니다.

$$f_{\mathbf{w},b}(x) = \sigma(\mathbf{w}^T x + b) = \frac{1}{1 + e^{-(\mathbf{w}^T x + b)}}$$

- **임계값(Threshold) 결정 규칙:**
    
    $$\hat{y} = \begin{cases} 1 & \text{if } f_{\mathbf{w},b}(x) \ge 0.5 \quad (z \ge 0) \\ 0 & \text{if } f_{\mathbf{w},b}(x) < 0.5 \quad (z < 0) \end{cases}$$
    

#### 2) 비용 함수 (Cost Function) - Binary Cross-Entropy (BCE)

- 시그모이드 함수를 적용하면 MSE 비용 함수가 비볼록(Non-convex) 형태가 되어 local minima에 갇힙니다. 
- 따라서 **로그 손실(Log Loss) / 이진 크로스 엔트로피** 함수를 사용합니다.

- **개별 데이터 손실 (Loss):**
    
    $$\text{Loss}(f(x), y) = \begin{cases} -\log(f(x)) & \text{if } y = 1 \\ -\log(1 - f(x)) & \text{if } y = 0 \end{cases}$$
    
- **전체 비용 함수 $J(\mathbf{w},b)$ (하나의 식으로 합친 형태):**
    
    $$J(\mathbf{w},b) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log\left(f_{\mathbf{w},b}(x^{(i)})\right) + (1 - y^{(i)}) \log\left(1 - f_{\mathbf{w},b}(x^{(i)})\right) \right]$$
    

#### 3) 경사 하강법 (Gradient Descent)

BCE 비용 함수 $J(\mathbf{w},b)$를 미분하면 흥미롭게도 **선형 회귀 때와 완전히 동일한 형태의 업데이트식**이 도출됩니다! (단, 여기서 $f(x)$는 시그모이드가 적용된 예측 확률입니다.)

- **가중치($w_j$) 업데이트:**
    
    $$w_j \leftarrow w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right) x_j^{(i)}$$
    
- **편향($b$) 업데이트:**
    
    $$b \leftarrow b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right)$$

## 2. Naive Bayes
- **베이즈 정리(Bayes' Theorem)**를 기반으로, 모든 입력 특성(Feature)들이 **서로 조건부 독립(Conditional Independence)이라는 순진한(Naive) 가정**을 통해 클래스 확률을 계산하여 분류하는 모델.
#### 0) 개요 및 핵심 특징

- **베이즈 정리 기반:** 새로운 데이터 $\mathbf{x} = (x_1, x_2, \dots, x_n)$이 주어졌을 때, 해당 데이터가 클래스 $y_k$에 속할 사후 확률 $P(y_k \mid \mathbf{x})$를 계산합니다.
    
- **"Naive(순진한)" 가정:** 모든 특성 $x_1, x_2, \dots, x_n$이 클래스 $y_k$가 주어졌을 때 **서로 완전히 독립적**이라고 가정합니다.
    
    - 예: '스팸 메일' 분류 시 "무료"라는 단어의 등장 확률과 "당첨"이라는 단어의 등장 확률이 서로 영향을 주지 않는다고 가정.
        

#### 1) 기본 수학 공식 (베이즈 정리)

$$P(y \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid y) P(y)}{P(\mathbf{x})}$$

- $P(y \mid \mathbf{x})$: **사후 확률 (Posterior)** — 데이터 $\mathbf{x}$가 주어졌을 때 클래스 $y$일 확률
    
- $P(\mathbf{x} \mid y)$: **가능도 (Likelihood)** — 클래스 $y$일 때 데이터 $\mathbf{x}$가 나타날 확률
    
- $P(y)$: **사전 확률 (Prior)** — 데이터 없이 클래스 $y$가 발생할 자체 확률
    
- $P(\mathbf{x})$: **증거 (Evidence)** — 데이터 $\mathbf{x}$가 등장할 전체 확률 (모든 클래스 비교 시 상수로 취급하여 생략 가능)
    

#### 2) 가설 함수 (Hypothesis Function / 분류 규칙)

- 조건부 독립 가정에 의해 가능도 $P(\mathbf{x} \mid y)$는 각 특성 확률의 곱으로 분해됩니다.

$$P(\mathbf{x} \mid y) = P(x_1, x_2, \dots, x_n \mid y) = \prod_{i=1}^{n} P(x_i \mid y)$$

- 따라서 나이브 베이즈의 최종 예측 클래스 $\hat{y}$는 사후 확률을 최대화하는 클래스(MAP, Maximum A Posteriori)로 선택됩니다.
- argmax 함수를 최대값으로 만드는 입력값(인덱스)을 찾는 연산이다.

$$\hat{y} = \arg\max_{y_k} P(y_k) \prod_{i=1}^{n} P(x_i \mid y_k)$$

#### 3) 대표 유형 (데이터 형태에 따른 분류)

1. **Gaussian Naive Bayes:** 연속형 데이터에 사용 (특성들이 정규분포를 따른다고 가정).
    
2. **Multinomial Naive Bayes:** 텍스트 데이터의 단어 빈도수(Count) 모델링에 주로 사용 (스팸 필터링, 문서 분류).
    
3. **Bernoulli Naive Bayes:** 특성들이 $0$ 또는 $1$(이진 값)로 존재 여부만 표현될 때 사용.
    

#### 4) 주요 장단점 및 주의사항

- **장점:**
    
    - 계산 복잡도가 작아서 **학습 및 예측 속도가 매우 큼**.
        
    - 텍스트 분류(스팸 메일, 감정 분석) 및 고차원 데이터에서 강력한 성능을 발휘.
        
    - 훈련 데이터 양이 적어도 비교적 잘 작동.
        
- **단점 및 한계:**
    
    - **독립성 가정이 현실과 다름:** 실제 데이터의 특성들은 서로 연관되어 있는 경우가 많음 (단, 실제 예측 성능은 이 가정이 깨져도 우수한 경우가 많음).
        
    - **Zero Frequency 문제:** 훈련 데이터에 한 번도 나오지 않은 단어나 특성이 들어오면 확률이 $0$이 되어 전체 결과가 $0$이 됨 $\rightarrow$ 라플라스 스무딩(Laplace Smoothing)을 적용하여 해결.

## 3. K-NN (k-최근접 이웃)

### 0). 주의 사항 / 개념
- 분류/회귀 전부 사용할 수 있다.
- **기억 기반 학습 (Instance-based Learning):** 별도의 모델 학습 과정이 없고, 새로운 데이터가 들어왔을 때 기존 데이터들과의 거리(Distance)를 계산하여 가장 가까운 $K$개의 이웃을 찾아 분류/회귀를 수행합니다.
    
- **게으른 학습 (Lazy Learning):** 훈련 단계에서는 데이터를 메모리에 저장만 해두고, 예측 시점에만 실제 계산을 시작합니다.
    
- **데이터 스케일링 필수:** 거리를 기준으로 판단하기 때문에, 변수 간 단주의 스케일 차이(예: 나이 0~100 vs 수입 0~10,000,000)가 크면 결과가 크게 왜곡됩니다. 반드시 표준화(Standardization)나 정규화(Normalization)가 선행되어야 합니다.
    
- **$K$의 선택:**
    
    - $K$가 너무 작으면: 이상치(Outlier)나 노이즈에 민감해져 **과대적합(Overfitting)** 위험이 커집니다.
        
    - $K$가 너무 크면: 모델이 단순해져 **과소적합(Underfitting)** 위험이 커집니다.
        
    - 보통 홀수로 설정하여 동점(Tie) 상황을 방지합니다.
        

### 1). 가설 함수 (Hypothesis Function)

- 새로운 입력 데이터 $\mathbf{x}$에 대하여, 전체 데이터셋 중 $\mathbf{x}$와 거리가 가장 가까운 $K$개의 이웃 집합을 $\mathcal{N}_K(\mathbf{x})$라고 정의합니다.

#### (1). 분류 (Classification)

- $K$개의 이웃 중 가장 많은 비중을 차지하는 클래스로 예측합니다 (다수결 투표, Majority Voting).
- 이웃 중 사과(4개), 바나나(1개) 이면, 다수결로 사과를 예측한다.
$$h_\theta(\mathbf{x}) = \arg\max_{c} \sum_{\mathbf{x}_i \in \mathcal{N}_K(\mathbf{x})} I(y_i = c)$$

- _(단, $I(\cdot)$는 조건이 참일 때 1, 거짓일 때 0을 반환하는 지시 함수)_

#### (2). 회귀 (Regression)

- $K$개의 이웃의 타깃 값 $y_i$들의 평균으로 예측합니다.
- K개의 이웃들의 숫자 값을 평균내고 이걸로 예측한다.
$$h_\theta(\mathbf{x}) = \frac{1}{K} \sum_{\mathbf{x}_i \in \mathcal{N}_K(\mathbf{x})} y_i$$

### 2). 비용 함수 (Cost Function)

> **K-NN에는 손실 함수(Loss)나 비용 함수(Cost)가 존재하지 않습니다.**

일반적인 파라미터 기반 모델(선형 회귀, 로지스틱 회귀 등)과 달리, K-NN은 **최적화할 파라미터(Weight $\mathbf{w}$, Bias $b$)가 없습니다.** 따라서 학습 과정에서 비용 함수를 정의하고 이를 최소화하는 과정을 거치지 않습니다.

대신, 성능 평가를 위해 예측 결과와 실제값 사이의 오차(분류: Accuracy/Cross-Entropy, 회귀: MSE/MAE)를 사후 검증(Validation) 지표로 측정하여 **최적의 $K$값**을 찾습니다.

### 3). 특징 및 업데이트식 (Update Equation)

#### (1). 파라미터 업데이트식의 부재

- 파라미터 최적화(Gradient Descent 등)를 통한 **업데이트식(Update Equation)은 존재하지 않습니다.**
    
- 학습(Fit) 알고리즘은 입력 데이터를 그대로 메모리나 공간 분할 트리를 위한 데이터 구조(KD-Tree, Ball-Tree 등)에 저장하는 것으로 완료됩니다.

#### (2). 거리 계산 공식 (Distance Metrics)

업데이트식 대신, 예측 단계에서 두 데이터 $\mathbf{x}_a$와 $\mathbf{x}_b$ 사이의 거리를 측정할 때 사용하는 주요 거리 공식입니다.

- **유클리드 거리 (Euclidean Distance, $L_2$ Norm):** 가장 흔히 사용되는 직선거리
- 두 점을 잇는 가장 짧은 눈자/직선거리 ($L_2$ Norm)
    
    $$d(\mathbf{x}_a, \mathbf{x}_b) = \sqrt{\sum_{j=1}^{p} (x_{a,j} - x_{b,j})^2}$$
    
- **맨해튼 거리 (Manhattan Distance, $L_1$ Norm):** 축을 따라 이동하는 격자형 거리
- 대각선으로 지질러 갈 수 없고, 오직 **가로·세로(축) 방향으로만 이동**할 수 있을 때의 총 거리입니다.
    $$d(\mathbf{x}_a, \mathbf{x}_b) = \sum_{j=1}^{p} \vert{}x_{a,j} - x_{b,j}\vert{}$$
    
- **민코프스키 거리 (Minkowski Distance):** $L_1, L_2$를 일반화한 거리 ($p=1$일 때 맨해튼, $p=2$일 때 유클리드)
- 민코프스키 거리는 새로운 개념이라기보다는, 파라미터 $p$의 값에 따라 맨해튼 거리도 되고 유클리드 거리도 되는 '통합 마스터 공식'입니다.    
    $$d(\mathbf{x}_a, \mathbf{x}_b) = \left( \sum_{j=1}^{p} \vert{}x_{a,j} - x_{b,j}\vert{}^p \right)^{\frac{1}{p}}$$
- **$p$에 따른 변화:**
	- **$p = 1$ 일 때:** 맨해튼 거리와 정확히 일치합니다. ($\sum \vert{}x_i - y_i\vert{}^1$)
	- **$p = 2$ 일 때:** 유클리드 거리와 정확히 일치합니다. ($\sqrt{\sum \vert{}x_i - y_i\vert{}^2}$)
	- **$p \to \infty$ 일 때:** 체비쇼프 거리(Chebyshev distance, 각 차원 차이 중 가장 큰 값)가 됩니다.

## 4. SVM (서포트 벡터 머신)

### 0). 개념 / 주의사항

- **개념:** 두 클래스(Class) 사이의 거리를 나타내는 **마진(Margin)을 최대화**하는 최적의 결정 경계(Hyperplane, 초평면)를 찾는 분류/회귀 알고리즘입니다.
    
- **서포트 벡터 (Support Vectors):** 경계면에 가장 가까이 위치한 데이터 포인트들을 의미하며, **오직 이 서포트 벡터들만이 결정 경계를 만드는 데 영향**을 미칩니다. (나머지 멀리 있는 데이터는 무시됨)
    
- **데이터 스케일링 필수:** k-NN과 마찬가지로 데이터 간 거리(Dot Product)를 기반으로 작동하기 때문에, 특성(Feature) 스케일링이 전제되어야 제대로 된 경계면이 형성됩니다.
    
- **C 하이퍼파라미터 (오차 허용치):**
    
    - **$C$가 크면 (Hard Margin에 가까움):** 오차를 거의 허용하지 않아 트레이닝 세트에 과대적합(Overfitting)될 위험이 커집니다.
        
    - **$C$가 작으면 (Soft Margin에 가까움):** 어느 정도 오차를 허용하여 마진을 넓게 가져가므로, 과소적합(Underfitting) 위험이 있습니다.
        
- **커널 트릭 (Kernel Trick):** 저차원에서는 선형 분리가 불가능한 데이터를 고차원 공간으로 매핑하여 선형 분리가 가능하도록 만드는 기법(RBF, Polynomial 등)을 사용합니다.
    

### 1). 가설 함수 설정 (Hypothesis Function)

- SVM은 결정 경계를 기준으로 데이터가 양수 영역인지 음수 영역인지 구분하여 클래스를 $+1$ 또는 $-1$로 예측합니다.

- 결정 경계의 방정식은 다음과 같이 정의됩니다:

$$\mathbf{w}^T \mathbf{x} + b = 0$$

- 이를 바탕으로 한 **가설 함수**는 부호 함수(Sign function)를 씌운 형태가 됩니다:

$$h_{\mathbf{w}, b}(\mathbf{x}) = \text{sign}(\mathbf{w}^T \mathbf{x} + b)$$

$$\text{where } \text{sign}(z) = \begin{cases} +1 & \text{if } z \ge 0 \\ -1 & \text{if } z < 0 \end{cases}$$

> **목표:** 올바르게 분류된 데이터는 $y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$ 조건을 만족하도록 만드는 것입니다.

### 2). 비용 함수 설정 (Cost Function)

- SVM의 마진 크기는 $\frac{2}{\Vert{}\mathbf{w}\Vert{}}$로 계산됩니다. 마진을 최대화하는 것은 $\frac{1}{2}\Vert{}\mathbf{w}\Vert{}^2$을 최소화하는 것과 같습니다.

- 현실 데이터의 오차를 허용하는 **Soft Margin SVM** 기준, 힌지 손실(Hinge Loss)과 $L_2$ 규제(Regularization)를 결합한 비용 함수(Cost Function)는 다음과 같습니다:

$$J(\mathbf{w}, b) = \frac{1}{2} \Vert{}\mathbf{w}\Vert{}^2 + C \sum_{i=1}^{N} \max\left(0, 1 - y_i(\mathbf{w}^T \mathbf{x}_i + b)\right)$$

- **$\frac{1}{2} \Vert{}\mathbf{w}\Vert{}^2$:** 마진 최대화를 위한 규제 항 (Margin Maximization)
    
- **$\max(0, 1 - y_i(\mathbf{w}^T \mathbf{x}_i + b))$:** 힌지 손실 (잘못 분류되거나 마진 경계 안으로 들어온 데이터에 대한 벌점)
    
- **$C$:** 마진 크기와 오차 허용 사이의 트레이드오프를 조절하는 규제 매개변수
    

### 3). 파라미터 업데이트 (Update Equation)

- SVM은 전통적으로 Quadratic Programming(二次 계획법)이나 SMO(Sequential Minimal Optimization) 알고리즘을 통해 쌍대 문제(Dual Problem)로 풀어내지만, **경사하강법(SGD)을 이용해 가중치 $\mathbf{w}$와 편향 $b$를 직접 업데이트**하는 방식도 자주 쓰입니다.

- 학습률(Learning Rate)을 $\alpha$라 할 때, $i$번째 데이터 포인트에 따른 경사하강법 업데이트 공식입니다:

#### (1). 올바르게 분류되었고 마진 밖에 있는 경우 ($y_i(\mathbf{w}^T \mathbf{x}_i + b) \ge 1$)

오차가 없으므로 마진 규제항만 고려하여 가중치를 줄여줍니다.

$$\mathbf{w} \leftarrow \mathbf{w} - \alpha \cdot \mathbf{w}$$

$$b \leftarrow b$$

#### (2). 잘못 분류되었거나 마진 내부에 있는 경우 ($y_i(\mathbf{w}^T \mathbf{x}_i + b) < 1$)

- 힌지 손실이 발생했으므로 손실을 줄이는 방향으로 가중치와 편향을 모두 조정합니다.

$$\mathbf{w} \leftarrow \mathbf{w} - \alpha \left( \mathbf{w} - C \cdot y_i \mathbf{x}_i \right)$$

$$b \leftarrow b + \alpha \cdot C \cdot y_i$$
