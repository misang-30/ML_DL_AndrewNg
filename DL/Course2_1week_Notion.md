- 딥러닝의 실용적인 측면을 다룬다. 
- 실제 모델을 훈련시킬 때 성능을 올리고 Overfitting을 막는 실무 테크닉을 다룬다.

## 1. 머신러닝의 실증적 세팅 
### 1). Train / Dev / Test Sets

- **데이터셋 분할 비율**:      
    - **과거 (소규모 데이터):** 60% / 20% / 20%
    - **빅데이터 시대 (100만 개 이상):** 98% / 1% / 1% (또는 Dev/Test 세트를 1만 개 정도로만 유지)
- **핵심 원칙**: Dev 세트와 Test 세트는 반드시 동일한 분포(Distribution)에서 수집되어야 함.
   
### 2). 편향(Bias) vs 분산(Variance)

- **High Bias (Underfitting):** Train Error가 높음 $\rightarrow$ 모델이 너무 단순함.
- **High Variance (Overfitting):** Train Error는 낮으나 Dev Error와의 격차가 큼 $\rightarrow$ 모델이 훈련 데이터에 과적합됨.
    
### 3). 머신러닝의 기본 레시피 

```
[Train Error가 높은가? (High Bias)]
 ├── Yes ➔ 더 큰 네트워크(층/뉴런 추가), 더 오래 훈련, 다른 최적화 알고리즘
 └── No  ➔ [Dev Error가 높은가? (High Variance)]
           ├── Yes ➔ 데이터 추가 수집, 정규화(Regularization), 네트워크 구조 변경
           └── No  ➔ 성공 (Done!)
```

## 2. 정규화 - Overfitting 해결책

### 1). L2 Regularization (Weight Decay)

비용 함수 $J$에 가중치 제곱합 패널티를 추가하여 가중치 $W$가 너무 커지지 않도록 억제합니다.

  

$$J(W, b) = \frac{1}{m} \sum_{i=1}^m \mathcal{L}(\hat{y}^{(i)}, y^{(i)}) + \frac{\lambda}{2m} \sum_{l=1}^L \Vert{}W^{[l]}\Vert{}_F^2$$

- **$\lambda$ (Lambda):** 정규화 하이퍼파라미터.
    
- **작동 원리:** $\lambda$가 커지면 가중치 $W$가 0에 가까워져, 수많은 뉴런의 영향력이 줄어들면서 복잡한 모델이 **더 단순한 모델로 변화**합니다.
### 2). 드롭아웃 (Dropout Regularization)

- 각 레이어에서 무작위로 뉴런을 일정 확률($1 - \text{keep\_prob}$)로 꺼버리고 훈련합니다.
- 특정 노드에만 의존하는 꼼수를 막기 위해, 매번 임의의 노드를 끄고 학습시키는 훈련법.
- 과적합은 특정 뉴런 몇 개가 너무 강한 가중치를 가져서, 그 뉴런 몇 개가 예측 전체를 휘두르는 현상이다.

- **Inverted Dropout (구현 방식):**
```python
# 훈련 시 (Train Time)
keep_prob = 0.8  # 80%의 뉴런은 살리고 20%는 끈다.

# 1. 80% 확률로 True/False를 가진 마스크 생성
d3 = np.random.rand(a3.shape[0], a3.shape[1]) < keep_prob

# 2. False가 된 뉴런의 출력을 0으로 만든다
a3 = a3 * d3

# 3. [핵심] 꺼진 20%의 에너지 손실을 메우기 위해 pozostałe 뉴런의 값을 1/0.8 배로 뻥튀기해준다
a3 = a3 / keep_prob

```

- **작동 원리:** 특정 특징에만 과도하게 의존하는 것을 방지하여 **가중치를 여러 뉴런으로 분산**시킵니다.
- **주의사항:** 테스트 단계(Test Time)에서는 드롭아웃을 적용하지 않습니다.

드롭아웃을 적용하면 각 학습 단계(Iteration)마다 설정한 확률(예: $50\%$)로 뉴런을 무작위로 꺼버립니다(출력을 0으로 만듦).

1. **특정 뉴런에 의존 불가:** 언제 꺼질지 모르므로, 신경망은 특정 특징(Feature) 하나에 올인하지 못하고 **여러 특징을 두루 살펴보는 법**을 배웁니다.
    
2. **가중치 분산:** 특정 가중치만 거대해지는 것을 막고, **가중치를 전체 뉴런으로 고르게 spreading**시킵니다. (이것이 수학적으로 L2 정규화와 유사한 효과를 냅니다.)
    
3. **앙상블(Ensemble) 효과:** 매 스텝마다 서로 다른 구조의 얇은 신경망을 새로 구성해서 학습시키는 셈이므로, 결국 **수천 개의 서로 다른 신경망을 합쳐서 예측하는 강력한 효과**가 생깁니다.

### 3). 기타 Overfitting 방지 기법

- **Data Augmentation:** 반전, 회전, 자르기 등으로 데이터 뻥튀기.
- **Early Stopping:** Dev Set의 오차가 증가하기 시작하는 시점에 훈련 조기 종료.

## 3. 최적화 문제의 세팅 (Optimization Problems)

### 1). 입력 데이터 스케일링 (Normalizing Inputs)

입력 $X$의 평균을 0으로, 분산을 1로 맞추는 작업입니다.

  

$$\mu = \frac{1}{m} \sum x^{(i)}, \quad \sigma^2 = \frac{1}{m} \sum (x^{(i)} - \mu)^2, \quad x := \frac{x - \mu}{\sigma}$$

- **이유:** 피처 간 스케일 차이가 크면 비용 함수 공면이 경사가 가파른 구겨진 모양이 되어 경사하강법이 진동합니다. 정규화를 하면 **동그란 구 형태**가 되어 훨씬 큰 학습률($\alpha$)로 빠르게 수렴할 수 있습니다.

### 2). 기울기 소실 / 폭주 (Vanishing / Exploding Gradients)

레이어가 매우 깊어지면($L$이 큼) 가중치가 1보다 약간만 작아도 $W^L$ 연산으로 인해 기울기가 0으로 소실되고, 1보다 약간만 크면 지수적으로 폭주합니다.

### 3). 가중치 초기화 (Weight Initialization) - 해결책

- 각 레이어의 입력 개수($n^{[l-1]}$)에 맞춰 가중치 초기 분산을 조정하여 기울기 소실/폭주를 완화합니다.
- 목표 : 신경망의 층을 통과하더라도 출력값 z의 분산(크가)이 폭발하거나 쪼그라들지 않고 1 근처로 일정하게 유지되게 만드는 것.
#### 단일 뉴런 관점에서의 문제

- 어떤 레이어의 선형 연산 $z = w_1 x_1 + w_2 x_2 + \dots + w_n x_n$ 을 생각해 봅시다.

- **입력 개수($n$)가 많아질수록**: 입력 $x$의 개수가 10개일 때보다 1,000개일 때, 이들을 다 더한 결과값 $z$의 크기(분산)는 훨씬 커집니다.
    
- 입력 유닛의 개수($n^{[l-1]}$)가 많다면, **가중치 $W$의 개별 값들을 더 작게 조정**해주어야 최종 합인 $z$의 크기가 일정하게 유지됩니다.

- **He Initializer (ReLU 활성화 함수용):**
``` python
W[l] = np.random.randn(shape) * np.sqrt(2 / n[l-1])
```
    
- **Xavier Initializer (tanh 활성화 함수용):**
``` python
W[l] = np.random.randn(shape) * np.sqrt(1 / n[l-1])
```

#### 설명

- **가중치가 조금만 크면:** 층을 거칠 때마다 $W$가 계속 곱해지면서 값이 지수적으로 커져 폭주(Exploding)하거나, 활성화 함수(Sigmoid/tanh)의 양끝 단으로 넘어가 포화(Saturation)되어 기울기가 0이 됩니다.
    
- **가중치가 조금만 작으면:** 층을 거칠 때마다 값이 계속 쪼그라들어 0으로 소실(Vanishing)됩니다.
    
- **따라서 초기화의 목적은:** 층이 아무리 깊어져도 값이 폭주하거나 0으로 사라지지 않도록, **'입력 뉴런 개수($n$)'에 맞춰 신호의 크기(분산)를 딱 1 근처로 일정하게 유지해 주는 시작점**을 붙잡아주는 것입니다.

- 결국 가중치 초기화(He / Xavier)는 deep한 신경망이 학습을 제대로 시작조차 못 하고 죽어버리는 것을 막기 위한 가장 첫 번째 안전장치라고 이해하시면 정확합니다

## 4. 경사 확인 (Gradient Checking) - 수식 디버깅

역전파로 구한 미분값($dW$)이 맞는지 수치 미분(Numerical Differentiation)을 통해 검증합니다.

- **공식:**
        $$f'(\theta) \approx \frac{f(\theta + \epsilon) - f(\theta - \epsilon)}{2\epsilon}$$
    
- **사용 팁:**  
    - Compution량이 많으므로 **디버깅할 때만 사용**하고, 실제 훈련 시에는 반드시 끌 것.
    - 드롭아웃을 사용 중이라면 드롭아웃을 끄고 경사 확인을 진행해야 함.
