1.학습 방식에 따른 분류

  2) 지도 학습 (Supervised)
     ├── 회귀 (Regression)
     │    ├── Linear Regression (선형 회귀)
     │    ├── Polynomial Regression (다항 회귀)
     │    └── Ridge / LASSO / ElasticNet
     └── 분류 (Classification)
          ├── Logistic Regression (로지스틱 회귀)
          ├── Naive Bayes (나이브 베이즈)
          ├── K-NN (k-최근접 이웃)
          ├── SVM (서포트 벡터 머신)
          ├── Decision Tree (결정 트리)
          └── Ensemble (Random Forest, XGBoost, LightGBM) *추가 추천

  3) 비지도 학습 (Unsupervised)
     ├── 군집화 (Clustering)
     │    ├── K-Means
     │    ├── DBSCAN
     │    ├── Agglomerative (계층적 군집화)
     │    └── GMM (가우시안 혼합 모델)
     ├── 연관 규칙 학습 (Association Rule)
     │    ├── Apriori
     │    └── FP-Growth
     └── 차원 축소 (Dimensionality Reduction)
          ├── PCA / SVD / LSA / t-SNE / UMAP (비지도)
          └── LDA (지도 기반 차원 축소)*

  4) 강화 학습 (Reinforcement)
     ├── Q-Learning
     ├── SARSA
     ├── DQN (Deep Q-Network)
     └── A3C / PPO / SAC


2.사용 알고리즘(구조)에 따른 분류

  1) 전통적 머신러닝 (수학 / 통계 / 나무 기반)
     └── 위 목록 중 신경망을 제외한 대부분 (선형 모델, Decision Tree, SVM, K-Means 등)

  2) 딥러닝 (인공신경망 기반)
     ├── DNN (다층 퍼셉트론)
     ├── CNN (시각 특화)
     ├── RNN / LSTM (시계열 특화)
     └── Transformer (대규모 맥락/텍스트 특화)
