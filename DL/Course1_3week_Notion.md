
# < Shallow Neural Network>

## 1. 로지스틱 회귀 vs 신경망 (Neural Network)

- **로지스틱 회귀 (Logistic Regression)**
    
    - 입력 데이터 $x$와 파라미터 $w, b$를 이용해 선형 계산 $z$를 구한 뒤, 시그모이드 활성화 함수를 통해 $a$($\hat{y}$)를 계산하고 손실(Loss)을 측정합니다.
        
    - **흐름:** $x \rightarrow z \rightarrow a (\hat{y}) \rightarrow L$
        
- **신경망 (Neural Network)**
    
    - 로지스틱 회귀에서 수행하던 **$z$ 계산과 $a$ 계산 구조를 여러 번 중첩(Stacking)하여 연결**한 형태입니다.
        

## 2. 신경망의 정방향 계산 (Forward Propagation)

신경망은 각 레이어(Layer)를 거치며 순차적으로 계산을 진행합니다.

1. **입력층 $\rightarrow$ 은닉층 (Layer 1):**
    
    - 입력 $x$와 첫 번째 레이어의 파라미터 $W^{[1]}, b^{[1]}$를 사용해 $z^{[1]}$을 계산합니다.
        
    - 활성화 함수(시그모이드 등)를 적용해 $a^{[1]}$을 계산합니다 ($a^{[1]} = \sigma(z^{[1]})$).
        
2. **은닉층 $\rightarrow$ 출력층 (Layer 2):**
    
    - $a^{[1]}$과 두 번째 레이어의 파라미터 $W^{[2]}, b^{[2]}$를 사용해 $z^{[2]}$를 계산합니다.
        
    - 다시 활성화 함수를 거쳐 최종 출력값 $a^{[2]}$($\hat{y}$)를 구합니다.
        
3. **손실 계산 (Loss Calculation):**
    
    - 예측값 $a^{[2]}$와 실제 정답 $y$를 비교하여 최종 손실(Loss)을 구합니다.
        

## 3. 노테이션(표기법) 구분

영상에서 강조하는 주요 표기법 차이는 다음과 같습니다.

- **대괄호 위지수 $z^{[1]}, a^{[1]}$**: 신경망의 **레이어(Layer) 번호**를 의미합니다. (예: Layer 1, Layer 2)
    
- **소괄호 위지수 $x^{(i)}$**: $i$번째 학습 데이터(Training Example)를 의미합니다.
    

## 4. 역방향 계산 (Backward Propagation)

- 정방향으로 구한 손실을 바탕으로, 오른쪽에서 왼쪽(출력층 $\rightarrow$ 입력층)으로 미분값을 계산하며 거꾸로 이동합니다.
    
- 이 과정을 통해 각 레이어의 경사(Gradient)인 $dW^{[2]}, db^{[2]}, dW^{[1]}, db^{[1]}$ 등을 구하여 파라미터를 업데이트합니다.

## 5. 입력층 및 활성화 값 표기법 ($a$)

- **$a$ (Activations, 활성화 값):** 각 레이어가 계산을 거쳐 **다음 레이어로 전달하는 값**을 의미합니다.
    
- **$a^{[0]}$ (입력층):** 입력 특성(Features) 벡터 $X$ 자체를 의미하며, $a^{[0]} = X$로 표기합니다.
    
- **$a^{[1]}$ (은닉층):** 첫 번째 레이어의 출력값입니다. 은닉 노드가 4개이므로 다음과 같이 **$4 \times 1$ 차원의 벡터**가 됩니다.
    
$$a^{[1]} = \begin{bmatrix} a_1^{[1]} \\ a_2^{[1]} \\ a_3^{[1]} \\ a_4^{[1]} \end{bmatrix}$$
    
- **$a^{[2]}$ (출력층):** 두 번째 레이어의 출력값이자 최종 예측값인 $\hat{y}$입니다.
    
    $$a^{[2]} = \hat{y}$$
    

## 6. 신경망 층수(Layer)를 세는 관례

- 영상에서 제시된 구조는 "2층 신경망 (2-layer Neural Network)"이라고 부릅니다.
    
- **층수 계산 규칙:** 신경망의 층수를 셀 때는 **입력층(Input Layer)을 공식적인 레이어로 포함하지 않습니다.**
    
    - **Layer 0:** 입력층 (Input Layer)
        
    - **Layer 1:** 은닉층 (Hidden Layer)
        
    - **Layer 2:** 출력층 (Output Layer)
        
- 논문이나 업계 표준에서도 입력층을 제외하고 계산하는 방식을 따릅니다.
    

## 7. 레이어별 파라미터($W, b$) 및 차원(Dimensions)

각 레이어는 전용 가중치($W$)와 편향($b$) 파라미터를 가집니다. 위 영상 예시(입력 3개, 은닉 노드 4개, 출력 노드 1개) 기준 차원은 다음과 같습니다.

### 은닉층 (Layer 1)

- **$W^{[1]}$ (가중치 행렬):** $4 \times 3$ 행렬
    
    - `4`: 현재 레이어의 은닉 노드 개수
        
    - `3`: 이전 레이어(입력층)의 특성 개수
        
- **$b^{[1]}$ (편향 벡터):** $4 \times 1$ 벡터
    

### 출력층 (Layer 2)

- **$W^{[2]}$ (가중치 행렬):** $1 \times 4$ 행렬
    
    - `1`: 현재 레이어(출력층)의 노드 개수
        
    - `4`: 이전 레이어(은닉층)의 노드 개수
        
- **$b^{[2]}$ (편향 벡터):** $1 \times 1$ (스칼라 값)
    

## 8. 로지스틱 회귀와의 표기법 비교

- **로지스틱 회귀:** 출력층이 단 하나뿐이므로 별도의 대괄호 지수 없이 $\hat{y} = a$로 표기했습니다.
    
- **신경망:** 레이어가 여러 개 존재하므로, 해당 값이 **몇 번째 레이어에서 나온 값인지 명확히 구분**하기 위해 대괄호 위지수($a^{[1]}, a^{[2]}$)를 필수적으로 사용합니다.

## 9. 개별 은닉 노드의 계산 원리 (Logistic Regression의 확장)

은닉층의 각 노드는 독립적인 로지스틱 회귀(Logistic Regression) 연산기처럼 작동하며, 2단계 연산($z$ 계산 후 $a$ 계산)을 수행합니다.

- **1번 은닉 노드 연산:**
    
    $$z_1^{[1]} = {w_1^{[1]}}^T x + b_1^{[1]}$$
    
    $$a_1^{[1]} = \sigma(z_1^{[1]})$$
    
- **2번 은닉 노드 연산:**
    
    $$z_2^{[1]} = {w_2^{[1]}}^T x + b_2^{[1]}$$
    
    $$a_2^{[1]} = \sigma(z_2^{[1]})$$
    
- **표기법 규칙 ($a_i^{[l]}$ / $z_i^{[l]}$):**
    
    - 위지수 대괄호 **$[l]$**: 레이어(Layer) 번호
        
    - 아래지수 **$_i$**: 해당 레이어 내 **$i$번째 노드(Node)** 번호
        

## 10. 은닉층의 벡터화 (Vectorization)

`for` 루프 없이 은닉층 전체 노드의 연산을 한 번에 처리하기 위해, 각 노드의 가중치 벡터들을 행렬로 쌓아 올려 벡터화를 진행합니다.

### 1). 가중치 행렬 $W^{[1]}$와 $z^{[1]}$의 벡터화

각 노드의 가중치 행 행렬들을 세로로 쌓아 가중치 행렬 $W^{[1]}$ ($4 \times 3$ 차원)을 만듭니다.

$$W^{[1]} = \begin{bmatrix} {w_1^{[1]}}^T \\ {w_2^{[1]}}^T \\ {w_3^{[1]}}^T \\ {w_4^{[1]}}^T \end{bmatrix}, \quad b^{[1]} = \begin{bmatrix} b_1^{[1]} \\ b_2^{[1]} \\ b_3^{[1]} \\ b_4^{[1]} \end{bmatrix}$$

이를 입력 벡터 $x$와 곱하면 $z^{[1]}$ 벡터 연산이 완성됩니다:

$$z^{[1]} = W^{[1]} x + b^{[1]} = \begin{bmatrix} z_1^{[1]} \\ z_2^{[1]} \\ z_3^{[1]} \\ z_4^{[1]} \end{bmatrix}$$

> **💡 벡터화 배치 규칙:** 한 레이어 안의 **서로 다른 노드들은 세로(행) 방향으로 쌓아서** 벡터/행렬을 구성합니다.

### 2). 활성화 값 $a^{[1]}$의 벡터화

시그모이드 함수 $\sigma$를 $z^{[1]}$ 벡터의 각 요소에 원소별(Element-wise)로 적용합니다.

$$a^{[1]} = \sigma(z^{[1]}) = \begin{bmatrix} a_1^{[1]} \\ a_2^{[1]} \\ a_3^{[1]} \\ a_4^{[1]} \end{bmatrix}$$

## 11. 2층 신경망 전체의 정방향 연산 (4줄의 코드)

단 하나의 입력 데이터 $x$가 주어졌을 때, 2층 신경망 전체의 출력을 구하는 계산 과정은 **단 4줄의 연산 공식**으로 정리됩니다.

1. **은닉층 선형 연산:** $z^{[1]} = W^{[1]} a^{[0]} + b^{[1]}$ $\quad (a^{[0]} = x)$
    
2. **은닉층 활성화:** $a^{[1]} = \sigma(z^{[1]})$
    
3. **출력층 선형 연산:** $z^{[2]} = W^{[2]} a^{[1]} + b^{[2]}$
    
4. **출력층 활성화 (최종 출력):** $a^{[2]} = \sigma(z^{[2]}) \quad (\hat{y} = a^{[2]})$
    

## 12. 레이어별 차원(Dimension) 및 역할 구조

|**연산 단계**|**공식**|**차원 (Dimensions)**|**비고**|
|---|---|---|---|
|**은닉층 (Layer 1)**|$z^{[1]} = W^{[1]}a^{[0]} + b^{[1]}$|$(4 \times 1) = (4 \times 3) \times (3 \times 1) + (4 \times 1)$|4개 은닉 노드의 병렬 연산|
||$a^{[1]} = \sigma(z^{[1]})$|$(4 \times 1) = \text{Element-wise } \sigma(4 \times 1)$|다음 층으로 전달되는 활성화 값|
|**출력층 (Layer 2)**|$z^{[2]} = W^{[2]}a^{[1]} + b^{[2]}$|$(1 \times 1) = (1 \times 4) \times (4 \times 1) + (1 \times 1)$|은닉층 결과 $a^{[1]}$을 입력으로 받음|
||$a^{[2]} = \sigma(z^{[2]})$|$(1 \times 1) = \text{Element-wise } \sigma(1 \times 1)$|최종 예측값 $\hat{y}$|

## 14. 명시적 `for` 루프 방식 (Non-Vectorized)

$m$개의 데이터를 순차적으로 처리하려면 아래와 같이 $1$부터 $m$까지 반복하는 `for` 루프가 필요합니다.

``` Python
for i in range(1, m + 1):
    z1[:, i] = W1 @ x[:, i] + b1
    a1[:, i] = sigmoid(z1[:, i])
    z2[:, i] = W2 @ a1[:, i] + b2
    a2[:, i] = sigmoid(z2[:, i])
```

> **문제점:** Python과 같은 환경에서 $m$번 반복하는 `for` 루프는 계산 속도를 크게 떨어뜨리므로, 행렬 연산을 통한 **벡터화(Vectorization)**가 필수적입니다.

## 15. $m$개 예제 전체의 벡터화 (Vectorized Implementation)

소문자 벡터 변수들을 **열(Column) 방향으로 쌓아 대문자 행렬**로 변환하면, `for` 루프 없이 단 4줄의 연산으로 전체 데이터셋을 일괄 처리할 수 있습니다.

### 1). 행렬 변환 구조


* **X (입력 행렬)**: 각 데이터 벡터 `x(1), x(2), ..., x(m)`을 **열(column) 방향으로 쌓은 행렬**

```text
X = [ x(1)  x(2)  ...  x(m) ]
```

* 크기(shape): **(n_x, m)**

  * `n_x`: 입력 특성(feature)의 개수
  * `m`: 데이터(샘플)의 개수

* **Z[1], A[1] (은닉층 행렬)**

```text
Z[1] = [ z[1](1)  z[1](2)  ...  z[1](m) ]

A[1] = [ a[1](1)  a[1](2)  ...  a[1](m) ]
```

* `Z[1]`: 은닉층의 선형 변환 결과
* `A[1]`: 활성화 함수가 적용된 은닉층 출력

각 열(column)은 하나의 학습 예제(sample)를 의미한다.


### 2). 벡터화된 정방향 연산 (4줄 연산 공식)

1. $Z^{[1]} = W^{[1]} X + b^{[1]}$
    
2. $A^{[1]} = \sigma(Z^{[1]})$
    
3. $Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}$
    
4. $A^{[2]} = \sigma(Z^{[2]})$
    

_(※ 이때 $b^{[1]}, b^{[2]}$는 파이썬 넘파이의 브로드캐스팅(Broadcasting)을 통해 각 열에 자동으로 더해집니다.)_

## 16. 행렬 $A$와 $Z$의 차원 및 축(Axis) 해석 방향

행렬 $A^{[1]}$ 또는 $Z^{[1]}$ 내의 위치에 따른 세부 구조는 다음과 같습니다.

```
                  ◄─── 가로 축 (Horizontal): 학습 데이터 예제 Index (1 to m) ───►
               ┌                                                                 ┐
               │  a_1^{[1](1)}    a_1^{[1](2)}    ...    a_1^{[1](m)}   │
세로 축        │  a_2^{[1](1)}    a_2^{[1](2)}    ...    a_2^{[1](m)}   │
(Vertical):    │  a_3^{[1](1)}    a_3^{[1](2)}    ...    a_3^{[1](m)}   │
은닉 노드 번호 │  a_4^{[1](1)}    a_4^{[1](2)}    ...    a_4^{[1](m)}   │
               └                                                                 ┘
```

- **가로 축 (Horizontal / Row-wise Sweep):** 왼쪽에서 오른쪽으로 이동하면 서로 다른 학습 데이터 예제($1$번째 $\rightarrow m$번째)를 스캔합니다.
    
- **세로 축 (Vertical / Column-wise Sweep):** 위에서 아래로 이동하면 동일한 데이터의 서로 다른 은닉 노드($1$번째 $\rightarrow n_h$번째)를 스캔합니다.
    
- **좌측 상단 원소 ($A_{1,1}$):** 첫 번째 학습 데이터($i=1$)에 대한 첫 번째 은닉 노드($j=1$)의 활성화 값 $a_1^{[1](https://gemini.google.com/app/1)}$을 나타냅니다.

## 17. 벡터화 연산의 수학적 정당성 ($Z^{[1]} = W^{[1]}X$ 증명)

편의를 위해 편향 $b^{[1]} = 0$이라 가정하고, 3개의 데이터 예제($x^{(1)}, x^{(2)}, x^{(3)}$)를 사용하여 행렬 곱셈의 정당성을 증명합니다.

### 1). 개별 예제에 대한 선형 연산

- 예제 1: $z^{[1](1)} = W^{[1]} x^{(1)}$ (열벡터)
    
- 예제 2: $z^{[1](2)} = W^{[1]} x^{(2)}$ (열벡터)
    
- 예제 3: $z^{[1](3)} = W^{[1]} x^{(3)}$ (열벡터)
    

### 2). 행렬 곱셈 관점에서의 통합

데이터 예제들을 열(Column) 방향으로 쌓아 만든 행렬 $$
X =
\begin{bmatrix}
x^{(1)} \\
x^{(2)} \\
x^{(3)}
\end{bmatrix}
$$
에 가중치 행렬 $W^{[1]}$를 곱하면, 선형대수학의 행렬 곱셈 규칙에 의해 각 열의 계산 결과가 독립적으로 배치됩니다.

$$W^{[1]} X = W^{[1]} \begin{bmatrix} x^{(1)} & x^{(2)} & x^{(3)} \end{bmatrix} = \begin{bmatrix} W^{[1]}x^{(1)} & W^{[1]}x^{(2)} & W^{[1]}x^{(3)} \end{bmatrix}$$

- W[1] X = [ z[1](1) z[1](2) z[1](3) ] = Z[1]

> **핵심 원리:** 입력값 $x^{(i)}$를 열 방향으로 나열하면, 선형 연산 결과인 $z^{[1](i)}$ 및 활성화 값 $a^{[1](i)}$ 역시 **동일한 순서의 열(Column) 방향으로 자동 배치**됩니다.

## 18. 파이썬 브로드캐스팅(Broadcasting)과 편향($b$)의 가산

실제 연산에서는 편향 벡터 $b^{[1]}$ ($n_h \times 1$ 차원)을 더해주어야 합니다.

$$Z^{[1]} = W^{[1]} X + b^{[1]}$$

- **차원 관계:** $(n_h \times m) = (n_h \times n_x) \times (n_x \times m) + (n_h \times 1)$
    
- **브로드캐스팅 동작:** NumPy 등의 라이브러리는 $n_h \times 1$ 차원의 벡터 $b^{[1]}$를 자동으로 $m$개의 열로 복사(확장)하여, $W^{[1]}X$ 행렬의 각 열에 개별적으로 더해줍니다.
    

## 19. 정방향 연산의 레이어간 대칭성 (Symmetry)

입력층 $X$를 레이어 0의 활성화 값인 $A^{[0]}$로 바꿔 쓰면, 신경망 연산 공식의 명확한 대칭성(Symmetry)을 확인할 수 있습니다.

|**레이어**|**선형 연산 (Z)**|**비선형 활성화 (A)**|
|---|---|---|
|**Layer 1 (은닉층)**|$Z^{[1]} = W^{[1]} \mathbf{A^{[0]}} + b^{[1]}$|$A^{[1]} = \sigma(Z^{[1]})$|
|**Layer 2 (출력층)**|$Z^{[2]} = W^{[2]} \mathbf{A^{[1]}} + b^{[2]}$|$A^{[2]} = \sigma(Z^{[2]})$|

- 이전 레이어의 출력값($A^{[l-1]}$)이 다음 레이어의 입력값이 되는 동일한 계산 패턴이 반복됩니다.
    
- 이 동일한 연산 구조는 향후 더 깊은 신경망(Deep Neural Network)으로 확장할 때도 동일하게 적용됩니다.

## 20. 활성화 함수(Activation Function)의 일반화

정방향 연산에서 선형 계산 결과인 $z$를 입력받아 최종 활성화 값 $a$를 출력하는 비선형 함수를 $g(z)$로 일반화하여 표기합니다.

$$a^{[l]} = g^{[l]}(z^{[l]})$$

- **$g^{[l]}$**: $l$번째 레이어에 사용된 활성화 함수
    
- 레이어마다 서로 다른 활성화 함수를 사용할 수 있습니다. (예: 은닉층에는 ReLU, 출력층에는 Sigmoid)
    

## 21. 주요 활성화 함수 4종 비교

### 1). 시그모이드 함수 (Sigmoid)

- **공식:** $a = \sigma(z) = \frac{1}{1 + e^{-z}}$
    
- **출력 범위:** $(0, 1)$
    
- **단점:** $z$가 너무 크거나 작으면 미분값(경사, Gradient)이 $0$에 가까워져 **경사 하강법(Gradient Descent) 학습 속도가 매우 느려집니다.**
    
- **권장 용도:** 이진 분류(Binary Classification) 문제의 출력층(Output Layer)에만 제한적으로 사용합니다.
    

### 2). 탄젠트 함수 (tanh / Hyperbolic Tangent)

- **공식:** $a = \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$
    
- **출력 범위:** $(-1, 1)$
    
- **장점:** 시그모이드 함수를 이동/확장한 형태로, **출력값의 평균(Mean)이 $0$에 가까워집니다.** 데이터를 원점 중심(Zero-centered)으로 맞추는 효과가 있어 다음 레이어의 학습을 훨씬 쉽게 만들며, **은닉층에서 시그모이드보다 거의 항상 우수합니다.**
    
- **단점:** $z$가 극단적일 때 미분값이 $0$으로 수렴하는 문제(Vanishing Gradient)는 여전히 존재합니다.
    

### 3). ReLU (Rectified Linear Unit) — 기본 표준(Default)

- **공식:** $a = \max(0, z)$
    
- **출력 범위:** $[0, \infty)$
    
- **장점:** $z > 0$ 영역에서는 기울기(미분값)가 항상 $1$로 유지됩니다. 이 덕분에 $z$의 넓은 영역에서 기울기가 $0$으로 꺼지는 현상이 방지되어 **tanh나 Sigmoid보다 학습 속도가 훨씬 빠릅니다.**
    
- **단점:** $z < 0$ 영역에서는 기울기가 $0$이 됩니다. (실제로는 많은 노드가 $z > 0$ 상태를 유지하므로 잘 동작함)
    
- **권장 용도:** 어떤 활성화 함수를 쓸지 고민될 때 **은닉층(Hidden Layer)의 기본 표준 선택지**입니다.
    

### 4). Leaky ReLU

- **공식:** $a = \max(0.01z, z)$
    
- **출력 범위:** $(-\infty, \infty)$
    
- **장점:** $z < 0$ 영역에서 $0$이 아닌 약간의 완만한 기울기($0.01$)를 부여하여, $z < 0$일 때 노드가 완전히 죽는 현상을 방지합니다.
    
- **변형:** 계수 $0.01$을 학습 가능한 파라미터로 만드는 버전(PReLU)도 존재합니다.
    

## 22. 활성화 함수 선택 가이드라인 (Rules of Thumb)

```
                            [문제 유형 / 레이어 위치]
                                        │
           ┌────────────────────────────┴────────────────────────────┐
           ▼                                                         ▼
    [은닉층 (Hidden Layer)]                                  [출력층 (Output Layer)]
           │                                                         │
     ┌─────┴─────┐                                             ┌─────┴─────┐
     ▼           ▼                                             ▼           ▼
  [ReLU]      [tanh]                                      [Sigmoid]     [기타]
(기본 권장)  (Zero-centered                            (이진 분류)   (회귀 등)
              가공 필요시)
```

1. **은닉층 (Hidden Layer):** **ReLU**를 기본 선택(Default)으로 사용합니다. 성능을 개선해보고 싶다면 **Leaky ReLU**나 **tanh**를 실험해봅니다.
    
2. **출력층 (Output Layer):**
    
    - **이진 분류 (Binary Classification):** $0 \sim 1$ 사이의 확률값이 필요하므로 **Sigmoid** 사용.
        
    - **기타 문제:** 문제 특성(회귀, 다중 클래스 등)에 맞는 적절한 함수 선택.
        
3. **실험적 검증:** 문제의 특성에 따라 최적의 활성화 함수가 달라질 수 있으므로, 검증 세트(Validation / Dev Set)에서 여러 함수를 직접 테스트해보고 가장 결과가 좋은 것을 선택하는 것이 정석입니다.

## 23. 선형 활성화 함수 (Linear / Identity Activation Function)

활성화 함수를 적용하지 않거나 $g(z) = z$ 형태로 설정하는 것을 **선형 활성화 함수(Linear Activation Function)** 또는 항등 활성화 함수(Identity Activation Function)라고 부릅니다.

이 경우 활성화 계산은 입력값을 아무런 비선형 변환 없이 그대로 출력합니다.

$$a^{[1]} = z^{[1]}$$

## 24. 은닉층에 비선형 활성화 함수가 필수적인 이유 (수학적 증명)

은닉층에 비선형 활성화 함수를 사용하지 않으면, **아무리 레이어를 깊게 쌓아도 단 하나의 선형 모델(로지스틱 회귀 또는 선형 회귀)과 완벽히 동일**해집니다.

### 수학적 합성 증명

2층 신경망에서 활성화 함수를 $g(z) = z$로 지정하면 다음과 같이 계산됩니다:

1. **Layer 1:** $a^{[1]} = z^{[1]} = W^{[1]} x + b^{[1]}$
    
2. **Layer 2 (출력층):** $a^{[2]} = z^{[2]} = W^{[2]} a^{[1]} + b^{[2]}$
    

이때 $a^{[1]}$의 식을 $a^{[2]}$에 대입하면:

$$a^{[2]} = W^{[2]} (W^{[1]} x + b^{[1]}) + b^{[2]}$$

$$a^{[2]} = (W^{[2]} W^{[1]}) x + (W^{[2]} b^{[1]} + b^{[2]})$$

새로운 가중치 $W' = W^{[2]} W^{[1]}$와 편향 $b' = W^{[2]} b^{[1]} + b^{[2]}$로 치환하면:

$$a^{[2]} = W' x + b'$$

> **💡 핵심 결론:** **선형 함수의 합성(Composition of Linear Functions)은 여전히 선형 함수입니다.** 따라서 은닉층에 비선형 변환이 없다면 100개의 은닉층을 쌓더라도 은닉층이 아예 없는 로지스틱 회귀/선형 회귀 모델과 표현력이 동일해집니다.

## 25. 선형 활성화 함수를 예외적으로 사용하는 경우

은닉층에는 **절대 선형 활성화 함수를 쓰지 않는 것이 원칙**이지만, 딱 한 가지 예외가 있습니다.

- **회귀 문제 (Regression Problem)의 출력층 (Output Layer):**
    
    - 주택 가격 예측과 같이 출력 $y$가 continuous한 실수 값 ( $-\infty \sim +\infty$ )인 경우, 출력층에선 선형 활성화 함수($g(z) = z$)를 사용하여 자유로운 범위의 실수를 출력하도록 설정할 수 있습니다.
        
    - _(단, 주택 가격처럼 음수가 나올 수 없는 경우 $a = \max(0, z)$ 형태의 ReLU를 출력층에 적용해 $y \ge 0$ 범위를 강제하기도 합니다.)_

## 27. 미분 기호 표기법 (Prime Notation)

역전파(Backpropagation) 과정에서 기울기(Slope)를 계산할 때, 미분 기호 $\frac{d}{dz}g(z)$의 간편한 축약형으로 **$g'(z)$** (g 프라임 z) 표기법을 사용합니다.

$$g'(z) = \frac{d}{dz} g(z)$$

## 28. 주요 활성화 함수의 도함수 공식 정리

역전파 구현 시 **이미 정방향 연산에서 계산해 둔 $a = g(z)$ 값을 활용하면 매우 빠르고 효율적으로 미분값을 산출**할 수 있습니다.

### 1). 시그모이드 함수 (Sigmoid Derivative)

- **기본 공식:** $g(z) = \frac{1}{1 + e^{-z}}$
    
- **도함수 공식:**
    
    $$g'(z) = g(z)\big(1 - g(z)\big) = a(1 - a)$$
    
- **특성 검증:**
    
    - $z = 10$ (매우 큼): $a \approx 1 \implies g'(z) \approx 1 \times (1 - 1) = 0$
        
    - $z = -10$ (매우 작음): $a \approx 0 \implies g'(z) \approx 0 \times (1 - 0) = 0$
        
    - $z = 0$: $a = 0.5 \implies g'(z) = 0.5 \times (1 - 0.5) = 0.25$ (최대 기울기)
        

### 2). 탄젠트 함수 (tanh Derivative)

- **기본 공식:** $g(z) = \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}}$
    
- **도함수 공식:**
    
    $$g'(z) = 1 - \big(\tanh(z)\big)^2 = 1 - a^2$$
    
- **특성 검증:**
    
    - $z = 10$ 또는 $z = -10$: $a \approx \pm 1 \implies g'(z) \approx 1 - (\pm 1)^2 = 0$
        
    - $z = 0$: $a = 0 \implies g'(z) = 1 - 0^2 = 1$ (최대 기울기)
        

### 3). ReLU 함수 (ReLU Derivative)

- **기본 공식:** $g(z) = \max(0, z)$
    
- **도함수 공식:**
    
    $$g'(z) = \begin{cases} 0 & \text{if } z < 0 \\ 1 & \text{if } z > 0 \\ 1 \text{ (또는 } 0\text{)} & \text{if } z = 0 \end{cases}$$
    

### 4). Leaky ReLU 함수 (Leaky ReLU Derivative)

- **기본 공식:** $g(z) = \max(0.01z, z)$
    
- **도함수 공식:**
    
    $$g'(z) = \begin{cases} 0.01 & \text{if } z < 0 \\ 1 & \text{if } z > 0 \\ 1 \text{ (또는 } 0.01\text{)} & \text{if } z = 0 \end{cases}$$
    

## 29. $z = 0$ 지점에서의 미분 불가능성 문제

ReLU 및 Leaky ReLU는 $z = 0$에서 꺾이는 점(Corner Point)이 존재하여 수학적으로는 엄밀한 미분(Derivative)이 정의되지 않습니다.

- **실제 구현에서의 해결책:** 소프트웨어 구현 시 컴퓨터 연산에서 $z$가 정확히 `0.0000000000`이 될 확률은 매우 극소수이므로 고려하지 않아도 무방합니다.
    
- 코드에서는 $z = 0$일 때 기울기를 $1$ 또는 $0$(Leaky ReLU의 경우 $0.01$) 중 하나로 임의 지정해 주면 실제 경사 하강법 학습에 아무런 지장을 주지 않습니다.
    
- 수학적 최적화 이론에서는 이를 서브그레이디언트(Subgradient, 하위 경사)의 개념으로 설명하며, 이 덕분에 최적화 알고리즘이 정상 작동합니다.

## 30. 신경망의 파라미터 및 차원 정리

입력 특성 개수가 $n^{[0]}$, 은닉층 노드 수가 $n^{[1]}$, 출력층 노드 수가 $n^{[2]}$ (이진 분류의 경우 $n^{[2]}=1$)일 때 각 파라미터의 차원은 다음과 같습니다.

- **가중치 (Weights):**
    
    - $W^{[1]}$ : $(n^{[1]} \times n^{[0]})$
        
    - $W^{[2]}$ : $(n^{[2]} \times n^{[1]})$
        
- **편향 (Biases):**
    
    - $b^{[1]}$ : $(n^{[1]} \times 1)$
        
    - $b^{[2]}$ : $(n^{[2]} \times 1)$
        

## 31. 경사 하강법(Gradient Descent)의 경계 및 업데이트 루프

매 반복(Iteration)마다 **초기화(Random Initialization) $\rightarrow$ 정방향 연산(Forward Prop) $\rightarrow$ 역전파(Backprop) $\rightarrow$ 파라미터 업데이트**의 순서로 실행됩니다.

### 파라미터 업데이트 공식 (학습률 $\alpha$)

$$W^{[1]} := W^{[1]} - \alpha \, dW^{[1]}$$

$$b^{[1]} := b^{[1]} - \alpha \, db^{[1]}$$

$$W^{[2]} := W^{[2]} - \alpha \, dW^{[2]}$$

$$b^{[2]} := b^{[2]} - \alpha \, db^{[2]}$$

## 32. 정방향 연산 (Forward Propagation) 요약

$m$개의 전체 학습 예제에 대해 벡터화된 4개의 기본 방정식입니다.

1. $Z^{[1]} = W^{[1]} X + b^{[1]}$
    
2. $A^{[1]} = g^{[1]}(Z^{[1]})$
    
3. $Z^{[2]} = W^{[2]} A^{[1]} + b^{[2]}$
    
4. $A^{[2]} = \sigma(Z^{[2]})$ _(이진 분류 기준 출력층은 Sigmoid)_
    

## 33. 역전파 연산 (Backpropagation) 핵심 6개 공식

역전파 단계에서는 정방향 연산의 역순으로 경사(Gradient)를 구합니다.

### ① 출력층 (Layer 2) 경사 계산

$$dZ^{[2]} = A^{[2]} - Y$$

$$dW^{[2]} = \frac{1}{m} dZ^{[2]} (A^{[1]})^T$$

$$db^{[2]} = \frac{1}{m} \text{np.sum}(dZ^{[2]}, \text{axis}=1, \text{keepdims}=\text{True})$$

> **참고:** 이진 분류($n^{[2]}=1$)에서의 $dZ^{[2]}$ 공식은 로지스틱 회귀와 형태가 완전히 일치합니다.

### ② 은닉층 (Layer 1) 경사 계산

$$dZ^{[1]} = (W^{[2]})^T dZ^{[2]} \odot g^{[1]'}(Z^{[1]})$$

$$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T$$

$$db^{[1]} = \frac{1}{m} \text{np.sum}(dZ^{[1]}, \text{axis}=1, \text{keepdims}=\text{True})$$

- **$\odot$ (Hadamard Product / Element-wise Product):** 두 행렬의 원소별 곱을 의미하며, 파이썬 NumPy에서는 `*` 연산자로 구현됩니다.
    
- **$g^{[1]'}(Z^{[1]})$:** 1번째 은닉층 활성화 함수의 미분값입니다.
    

## 34. NumPy 구현 팁: `keepdims=True`의 중요성

`np.sum` 연산을 수행할 때 `keepdims=True` 옵션을 지정해야 차원이 1차원 배열(`(n,)`)로 축소되는 랭크-1 배열(Rank-1 array) 현상을 방지할 수 있습니다.

- **이유:** 편향 $b^{[1]}$ 및 $db^{[1]}$은 정확히 $(n^{[1]} \times 1)$ 형태의 **2차원 열벡터** 형태를 유지해야 브로드캐스팅 오류나 행렬 연산 왜곡이 발생하지 않습니다.

## 35. 계산 그래프(Computation Graph)에서의 정방향 및 역전파 흐름

역전파는 복잡한 신경망 연산을 작은 단계로 쪼갠 후, 계산 그래프 상에서 오른쪽(손실 함수)에서 왼쪽(입력층) 방향으로 연쇄 법칙(Chain Rule)을 적용해 기울기를 구하는 과정입니다.

### 정방향 연산 (Left to Right)

$$x \longrightarrow z^{[1]} \longrightarrow a^{[1]} \longrightarrow z^{[2]} \longrightarrow a^{[2]} (\hat{y}) \longrightarrow \mathcal{L}(a^{[2]}, y)$$

### 역전파 연산 (Right to Left)

$$\mathcal{L} \longrightarrow da^{[2]} \longrightarrow dz^{[2]} \longrightarrow (dw^{[2]}, db^{[2]}) \longrightarrow da^{[1]} \longrightarrow dz^{[1]} \longrightarrow (dw^{[1]}, db^{[1]})$$

> **참고:** 감독 학습(Supervised Learning)에서 입력 데이터 $x$는 고정된 값이므로, $x$에 대한 미분($dx$)은 파라미터 업데이트에 필요하지 않아 계산하지 않습니다.

## 36. 미분 연쇄 법칙(Chain Rule)을 통한 $dz$ 도출

로지스틱 회귀 및 출력층에서 $dz^{[2]} = a^{[2]} - y$라는 간결한 공식이 나오는 근거는 미적분학의 연쇄 법칙 때문입니다.

1. 손실 함수 $\mathcal{L}$을 $z$에 대해 미분:
    
    $$\frac{\partial \mathcal{L}}{\partial z} = \frac{\partial \mathcal{L}}{\partial a} \cdot \frac{\partial a}{\partial z}$$
    
2. 로지스틱 회귀에서 $a = \sigma(z)$이므로 $\frac{\partial a}{\partial z} = g'(z) = a(1 - a)$입니다.
    
3. $\frac{\partial \mathcal{L}}{\partial a} = -\frac{y}{a} + \frac{1-y}{1-a}$를 대입하여 정리하면 다음과 같이 축약됩니다:
    
    $$dz = \left(-\frac{y}{a} + \frac{1-y}{1-a}\right) \cdot a(1 - a) = a - y$$
    

## 37. 전치 행렬(Transpose)이 붙는 이유와 차원 일치 법칙 (Dimension Matching)

역전파 공식을 유도하거나 구현할 때 오류를 줄이는 가장 중요한 규칙은 **변수 $foo$와 그것의 기울기 $dfoo$는 반드시 동일한 차원(Shape)을 가져야 한다**는 것입니다.

### 1) $a^{[1]T}$ 및 $W^{[2]T}$ 전치가 추가되는 이유

- **로지스틱 회귀:** $dw = dz \cdot x$
    
- **신경망 Layer 2:** $dW^{[2]} = dZ^{[2]} (A^{[1]})^T$
    
    - $W^{[2]}$가 $(n^{[2]} \times n^{[1]})$ 행렬이고, $dZ^{[2]}$가 $(n^{[2]} \times 1)$, $A^{[1]}$이 $(n^{[1]} \times 1)$일 때, $dW^{[2]}$가 $(n^{[2]} \times n^{[1]})$ 차원을 만족하려면 $A^{[1]}$에 전치(Transpose)를 취해야 합니다.
        

### 2) 은닉층 경사 $dZ^{[1]}$의 차원 검증

$$dZ^{[1]} = (W^{[2]})^T dZ^{[2]} \odot g^{[1]'}(Z^{[1]})$$

|**항**|**차원 (Dimensions)**|
|---|---|
|**$dZ^{[1]}$**|$(n^{[1]} \times 1)$|
|**$(W^{[2]})^T$**|$(n^{[1]} \times n^{[2]})$ _(원본 $W^{[2]}$는 $n^{[2]} \times n^{[1]}$)_|
|**$dZ^{[2]}$**|$(n^{[2]} \times 1)$|
|**$(W^{[2]})^T dZ^{[2]}$**|$(n^{[1]} \times n^{[2]}) \times (n^{[2]} \times 1) = \mathbf{(n^{[1]} \times 1)}$|
|**$g^{[1]'}(Z^{[1]})$**|$(n^{[1]} \times 1)$|

> **디버깅 팁:** 역전파 코드를 작성할 때 각 행렬의 차원이 위와 같이 일치하는지 점검하는 것만으로도 대부분의 버그를 사전에 방지할 수 있습니다.

## 38. $m$개 샘플에 대한 벡터화(Vectorized) 역전파 요약

단일 예제 공식을 전체 $m$개 학습 데이터 세트 행렬($X, Z, A$)로 확장하면 다음과 같습니다.

$$dZ^{[2]} = A^{[2]} - Y \quad (n^{[2]} \times m)$$

$$dW^{[2]} = \frac{1}{m} dZ^{[2]} (A^{[1]})^T \quad (n^{[2]} \times n^{[1]})$$

$$db^{[2]} = \frac{1}{m} \text{np.sum}(dZ^{[2]}, \text{axis}=1, \text{keepdims}=\text{True}) \quad (n^{[2]} \times 1)$$

$$dZ^{[1]} = (W^{[2]})^T dZ^{[2]} \odot g^{[1]'}(Z^{[1]}) \quad (n^{[1]} \times m)$$

$$dW^{[1]} = \frac{1}{m} dZ^{[1]} X^T \quad (n^{[1]} \times n^{[0]})$$

$$db^{[1]} = \frac{1}{m} \text{np.sum}(dZ^{[1]}, \text{axis}=1, \text{keepdims}=\text{True}) \quad (n^{[1]} \times 1)$$

- 전체 평균 손실을 구하기 때문에 $dW$와 $db$ 연산에는 **$\frac{1}{m}$** 스케일링이 추가됩니다.

## 39. 가중치를 0으로 초기화할 때 발생하는 문제: 대칭성 문제 (Symmetry Problem)

로지스틱 회귀와 달리, 신경망에서 가중치 행렬 $W$의 모든 요소를 $0$으로 초기화하면 대칭성 깨기(Symmetry Breaking)에 실패하여 학습이 제대로 진행되지 않습니다.

### 수학적 증명 및 메커니즘

1. **동일한 정방향 출력:** $W^{[1]} = 0$이면 입력 데이터 $x$에 상관없이 $z^{[1]} = 0$이 되며, 결과적으로 은닉층의 모든 노드가 동일한 활성화 값($a_1^{[1]} = a_2^{[1]} = \dots$)을 출력합니다.
    
2. **동일한 역전파 기울기:** 역전파 과정에서도 동일한 미분값이 전달되어 $dW^{[1]}$의 모든 행(Row)이 동일한 값을 갖게 됩니다.
    
3. **귀납법(Induction)에 의한 대칭성 유지:**
    
    $$W^{[1]} := W^{[1]} - \alpha \, dW^{[1]}$$
    
    학습을 아무리 오래 진행하더라도 모든 은닉 노드가 여전히 동일한 함수를 계산하게 되며, **노드가 여러 개 존재하는 의미(표현력)를 완전히 상실**하게 됩니다.
    

## 40. 가중치 무작위 초기화 (Random Initialization) 구현

대칭 문제를 해결하려면 가중치 $W$를 무작위 난수(Random Values)로 초기화해야 합니다. 반면, **편향(Bias) $b$는 $0$으로 초기화해도 아무런 문제가 없습니다.**


``` Python
import numpy as np

# Layer 1 초기화 (예: n_h = 2, n_x = 2)
W1 = np.random.randn(2, 2) * 0.01
b1 = np.zeros((2, 1))

# Layer 2 초기화 (예: n_y = 1, n_h = 2)
W2 = np.random.randn(1, 2) * 0.01
b2 = np.zeros((1, 1))
```

- **`np.random.randn(d0, d1)`**: 표준 가우시안 정규분포(평균 0, 표준편차 1)를 따르는 난수 행렬을 생성합니다.
    
- 가중치 $W$가 다르게 출발하므로 각 은닉 노드가 서로 다른 특징(Feature)을 학습하게 됩니다.
    

## 41. 가중치를 '매우 작은 값($0.01$)'으로 설정해야 하는 이유

가중치 난수에 $0.01$을 곱해 매우 작게 만드는 이유는 **활성화 함수의 포화(Saturation) 현상을 방지**하기 위함입니다.

- **원리:**
    
    $$z = Wx + b$$
    
    $W$의 절대값이 너무 크면 계산되는 $z$ 값 또한 너무 커지거나 너무 작아지게 됩니다.
    
- **영향:**
    
    Sigmoid나 tanh 같은 활성화 함수는 $z$의 절대값이 커지면 완만하고 평평한 구간(Flat region)에 진입하게 됩니다.
    
- **결과:**
    
    이 구간에서는 미분 기울기(Slope)가 $0$에 매우 가까워져 **경사 하강법의 학습 속도가 극도로 느려집니다.**
    

> **참고:** 얕은 신경망(Shallow Network)에서는 $0.01$을 곱해주는 것이 잘 작동하지만, 층이 매우 깊은 신경망(Deep Network)에서는 Xavier 초기화나 He 초기화와 같이 더 적절한 가중치 초기화 기법을 적용해야 합니다.
