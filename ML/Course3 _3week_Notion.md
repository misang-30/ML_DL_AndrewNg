

## 1. 강화학습(Reinforcement Learning)의 기본 개념

### 1). 강화학습 개요

#### (1). 모델의 정의 및 작동 방식

- **기본 정의:** 보상 함수(Reward Function)를 기반으로 바람직한 행동에는 보상을 주고, 부정적인 행동에는 벌을 주어 목표 행동을 학습시키는 비지도 학습 모델 기법입니다.
    
- **상태 및 터미널 상태:** 모델은 의사결정을 내려야 하는 '상태(State)'를 반복 구사합니다. 원하는 최종 조건인 '터미널 상태(Terminal State)'에 도달하면 학습이 종료되며, 이후에는 보상이 주어지지 않습니다.
    
- **중간 보상과 시간 단계:** 중간 상태에는 보상을 적게(또는 0으로) 설정하여 알고리즘이 비효율적인 경로나 무한 루프에 빠지지 않고 계속 나아가도록 유도합니다.
    
- **상태 전이 함수:** 각 단계는 상태 $s$, 행동 $a$, 보상 $R(s)$, 다음 상태 $s'$의 관계식으로 표현됩니다:
    
    $$\text{Algorithm} \rightarrow (s, a, R(s), s')$$
    
- **마르코프 결정 과정 (MDP):** 미래 상태는 오직 현재 상태에만 의존하며, 과거에 어떻게 도달했는지는 고려하지 않습니다.
    - 이 명제에서 말하는 핵심은 "과거가 중요하지 않다"가 아니라, "과거의 모든 영향이 이미 '현재 상태' 안에 다 축적되어 찍혀 있다"는 뜻입니다.

### 2). 리턴(Return)과 할인율(Discount Factor)

#### (1). 리턴의 정의

- 시간에 따른 보상들을 종합 비교 및 가중 평가하여 행동의 우수성을 판단하는 기준입니다.
    
- 각 단계의 보상 $R$을 할인율 $\gamma$ (gamma)로 할인하여 터미널 상태까지 합산합니다:
    
    $$\text{Return} = R_1 + \gamma R_2 + \gamma^2 R_3 + \dots$$
    

#### (2). 할인율($\gamma$)의 역할

- $\gamma$ 값이 작을수록 빠르게 목표를 달성하도록 촉진합니다.
    
- 부정적인 보상 시스템에서는 할인율로 인해 시스템이 음의 보상을 가능한 한 미래로 미루려는 경향을 보이기도 합니다.
    

### 3). 정책(Policy)

#### (1). 정책의 역할

- 입력 상태 $s$를 행동 $a$에 매핑하는 규칙입니다:
    
    $$\pi(s) = a$$
    
- 최종 목적은 모든 가능한 상태에 대해 리턴을 최대화하는 행동을 찾아내는 최적의 정책을 구축하는 것입니다.
    

## 2. 핵심 알고리즘 및 수학적 모델

### 1). 상태-행동 가치 함수 (Q-함수)

#### (1). Q-함수 $Q(s, a)$의 역할

- 상태 $s$에서 행동 $a$를 취한 뒤, 그 이후로는 최적으로 행동했을 때 얻을 수 있는 리턴의 기대값을 나타냅니다.
    
- 모든 가능한 행동 중에서 리턴을 최대화하는 값을 선택합니다:
    
    $$\max_{a} Q(s, a)$$
    

### 2). 벨만 방정식 (Bellman Equation)

#### (1). 결정론적 환경에서의 벨만 방정식

- 현재 보상과 다음 단계의 최적 리턴 간의 관계를 재귀적으로 정의한 방정식입니다.
    
    $$Q(s, a) = R(s) + \gamma \max_{a'} Q(s', a')$$
    
- 터미널 상태에 도달하면 $Q(s, a) = R(s)$로 단순화되어 보상이 재귀 트리를 따라 역전파됩니다.
    

### 3). 무작위(확률적) 환경 (Stochastic Environments)

#### (1). 확률적 환경에서의 특성

- 외부 요인(예: 로봇이 걸어가다 미끄러짐)으로 인해 행동 결과에 불확실성이 존재하는 환경입니다.
    
- 단일 시행이 아닌, 여러 차례 시도의 평균 보상 기대값 $E$를 최대화하는 것을 목표로 합니다:
    
    $$\text{Return} = E[R_1 + \gamma R_2 + \gamma^2 R_3 + \dots]$$
    

#### (2). 확률적 벨만 방정식

- 미래 상태 및 행동에 대한 기댓값 $E$를 반영하여 수정됩니다:
    
    $$Q(s, a) = R(s) + \gamma E\left[\max_{a'} Q(s', a')\right]$$
    

## 3. 심층 강화학습과 신경망 (Deep Q-Learning)

### 1). 연속적 상태 공간 및 신경망 적용

#### (1). 연속 상태 공간 (Continuous State Spaces)

- 상태가 이산적인 값이 아닌 범위나 연속된 스펙트럼(예: 자율주행차의 위치 $x, y$, 회전각 $\theta$, 속도 $\dot{x}, \dot{y}$, 가속도 $\ddot{x}, \ddot{y}$) 형태를 갖는 경우입니다.
    

#### (2). 상태-가치 함수와 신경망

- 신경망의 입력 $x$로 상태와 행동 $(s, a)$을 전달하고, 출력 $y$로 Q-값 $Q(s, a)$을 예측하도록 지도 학습 구조를 적용합니다.
    
- 지도 학습 목표 함수:
    
    $$f_{w,b}(x) \approx y$$
    
    $$x^{(i)} = (s^{(i)}, a^{(i)})$$
    
    $$y^{(i)} = R(s^{(i)}) + \gamma \max_{a'} Q({s'}^{(i)}, a')$$
    

### 2). 전체 학습 알고리즘 과정

#### (1). 리플레이 버퍼 (Replay Buffer)

- 과도한 메모리 부하를 방지하기 위해 최근에 수집된 튜플 $(s, a, R(s), s')$의 일부만 저장하여 학습 데이터로 활용합니다.
    

#### (2). 학습 알고리즘 요약

1. 신경망의 파라미터(가중치)를 무작위로 초기화하여 초기 $Q(s, a)$를 생성합니다.
    
2. 탐색을 수행하고 데이터 튜플 $(s, a, R(s), s')$을 수집하여 리플레이 버퍼에 저장합니다.
    
3. 상태-가치 함수를 이용해 입력 $x=(s, a)$와 목표 출력 $y = R(s) + \gamma \max_{a'} Q(s', a')$로 신경망을 학습시킵니다.
    
4. 학습된 새 예측 모델 $Q_{new}$를 다음 루프의 기존 Q-함수로 업데이트합니다 ($Q = Q_{new}$).
    

## 4. 학습 알고리즘 개선 및 최적화 기법

### 1). 신경망 아키텍처 개선

#### (1). 출력층 구조 변경

- 단일 행동만 출력하는 대신, 가능한 모든 행동에 대한 Q-값을 출력층의 각 유닛으로 한 번에 계산하여 최적의 리턴을 더 빠르게 탐색합니다.
    
- 이는 벨만 방정식의 $\max_{a'} Q(s', a')$ 계산을 매우 효율적으로 만들어 줍니다.
    

### 2). $\epsilon$-Greedy 정책 (Epsilon-Greedy Policy)

#### (1). 탐욕(Greedy) 기법과 탐색(Exploration)의 조화

- **Greedy (확률 $P$, 예: 95%):** 기존에 알려진 최적의 행동 $\max_{a} Q(s, a)$을 선택합니다.
    
- **Exploration (확률 $1-P = \epsilon$, 예: 5%):** 무작위 행동을 선택하여 새로운 경로를 탐색합니다.
    
- 학습 초기에는 $\epsilon$ 값을 높게 설정하여 다양한 시도를 하도록 유도하고, 학습이 진행될수록 $\epsilon$을 줄여 최적 행동에 집중하도록 만듭니다.
    

### 3). 미니배치 (Mini-batch)

#### (1). 미니배치의 장점

- 전체 리플레이 버퍼 중 일부 데이터 조각 $m'$만을 추출해 경사하강법(Gradient Descent)을 수행함으로써 계산 시간을 크게 단축합니다.
    
- 전체 배치 방식에 비해 다소 노이즈가 발생하지만, 계산 자원 사용량을 크게 줄이면서 최적점에 원활하게 도달합니다.
    

### 4). 소프트 업데이트 (Soft Updates)

#### (1). 소프트 업데이트의 작동 원리

- 매 루프마다 $Q = Q_{new}$로 갑작스럽게 변경하는 대신, 이전 파라미터 값을 일정 비율 반영하여 점진적으로 업데이트합니다.
    
- 소수 비율 $p$ (예: 1%)에 대해 파라미터 업데이트 식:
    
    $$w = (p)w_{new} + (1-p)w$$
    
    $$b = (p)b_{new} + (1-p)b$$
    
- 노이즈나 일시적으로 잘못된 단계에 의해 성능이 급격히 저하되는 현상을 방지하고 안정적인 수렴을 돕습니다.
