## 1. 안면 인식 (Face Recognition)의 기초와 과제

### 안면 검증(Verification) vs 안면 인식(Recognition)

* **안면 검증 (1:1 문제):** 입력 이미지와 이름(또는 ID)을 받아 "이 사람이 해당 ID의 주인이 맞는지" 확인합니다. (비교적 쉬운 문제)
* **안면 인식 (1:N 문제):** 입력 이미지 하나만 주어지면, 시스템 내 $N$명의 데이터베이스를 모두 뒤져서 "이 사람이 누구인지" 맞추는 문제입니다. (인식 대상 $N$명이 많아질수록 정확도 요구치가 기하급수적으로 올라감)

### 원샷 학습 (One-Shot Learning)

안면 인식 시스템의 가장 큰 난관은 데이터의 양입니다. 직원이 1,000명인 회사에서 각 직원당 사진을 단 1장(또는 몇 장)만 가지고 시스템을 구축해야 합니다.

* **일반적인 CNN의 한계:** 1,000개의 클래스를 분류하는 Softmax 레이어를 만들면, 신입사원이 들어올 때마다 네트워크를 처음부터 다시 학습시켜야 하므로 실전에서 사용이 불가능합니다.
* **해결책 (Similarity Function):** 이미지의 클래스를 직접 맞추는 대신, 두 이미지 간의 차이(유사도)를 계산하는 함수 $d(\text{img1, img2})$를 학습시킵니다.

## 2. 시아미즈 네트워크 (Siamese Network)

원샷 학습을 구현하는 핵심 아키텍처입니다. '샴쌍둥이'에서 이름을 딴 이 구조는 **가중치(Parameters)를 완전히 공유하는 동일한 두 개의 CNN**을 병렬로 배치합니다.

### 동작 원리

1. 첫 번째 이미지 $x^{(1)}$을 CNN에 통과시켜 마지막 레이어에서 고차원 특징 벡터(임베딩, Embedding) $f(x^{(1)})$을 얻습니다. (예: 128차원의 벡터)
2. 두 번째 이미지 $x^{(2)}$를 **동일한** CNN에 통과시켜 임베딩 $f(x^{(2)})$를 얻습니다.
3. 두 사람이 같은 사람이면 두 벡터 사이의 거리 $d$가 작아지고, 다른 사람이면 거리 $d$가 커지도록 신경망의 가중치를 학습시킵니다.

$$d(x^{(1)}, x^{(2)}) = \vert{}\vert{}f(x^{(1)}) - f(x^{(2)})\vert{}\vert{}_2^2$$

## 3. 트리플렛 손실 (Triplet Loss)

시아미즈 네트워크를 올바르게 학습시키기 위해 사용하는 특수한 손실 함수입니다. 학습을 위해 항상 3개의 이미지 세트(Triplet)가 동시에 필요합니다.

### 3가지 이미지의 정의

* **Anchor ($A$):** 기준이 되는 특정 인물의 사진
* **Positive ($P$):** Anchor와 **동일한** 인물의 다른 사진
* **Negative ($N$):** Anchor와 **다른** 인물의 사진

### 목적 함수와 마진(Margin)

기본적인 목표는 Anchor와 Positive 사이의 거리는 최소화하고, Anchor와 Negative 사이의 거리는 최대화하는 것입니다.

$$\vert{}\vert{}f(A) - f(P)\vert{}\vert{}^2 \le \vert{}\vert{}f(A) - f(N)\vert{}\vert{}^2$$

이 식을 그대로 쓰면 신경망이 모든 임베딩 값을 그냥 `0` 벡터로 출력하여 쉽게 만족해 버리는 꼼수(Trivial solution)를 부립니다. 이를 방지하기 위해 최소한의 안전거리인 마진(Margin, $\alpha$)을 더해 다음과 같이 손실 함수를 정의합니다.

$$\mathcal{L}(A, P, N) = \max \left( \vert{}\vert{}f(A) - f(P)\vert{}\vert{}^2 - \vert{}\vert{}f(A) - f(N)\vert{}\vert{}^2 + \alpha, \; 0 \right)$$

* 전체 데이터셋의 총 손실(Loss)은 모든 Triplet 쌍에 대한 $\mathcal{L}$의 합입니다.

### 마이닝 에러 (Hard Negative Mining)

Triplet 쌍을 무작위로 고르면 $\vert{}\vert{}f(A) - f(P)\vert{}\vert{}^2$이 $\vert{}\vert{}f(A) - f(N)\vert{}\vert{}^2$보다 훨씬 작아서 신경망이 배울 점이 없는 경우가 많습니다. 따라서 학습 효율을 극대화하려면 **학습하기 어려운(Hard) 조건의 데이터**를 골라야 합니다. 즉, 실제로는 다른 사람이지만 얼굴이 교묘하게 닮아 거리가 비슷하게 나오는 조건인 **$\vert{}\vert{}f(A) - f(P)\vert{}\vert{}^2 \approx \vert{}\vert{}f(A) - f(N)\vert{}\vert{}^2$** 쌍을 적극적으로 찾아내어 미니배치를 구성해야 학습이 빠르게 진행됩니다.

## 4. 안면 검증의 이진 분류(Binary Classification) 구현

트리플렛 손실 외에 안면 인식을 구현하는 또 다른 실전 방법입니다. 시아미즈 네트워크를 통해 두 이미지의 임베딩($f(x^{(i)}), f(x^{(j)})$)을 뽑아낸 뒤, 이를 **이진 분류(Logistic Regression)의 입력**으로 사용하는 방식입니다.

$$\hat{y} = \sigma \left( \sum_{k=1}^{128} w_k \vert{}f(x^{(i)})_k - f(x^{(j)})_k\vert{} + b \right)$$

* 두 임베딩 벡터의 각 원소별 차이의 절대값을 가중치 $w_k$와 곱하고 시그모이드($\sigma$)를 씌워 `1(동일인)` 또는 `0(타인)`을 예측하게 만듭니다. 데이터베이스 안의 사진들은 임베딩을 미리 계산해 두고, 새로 들어온 사진의 임베딩만 뽑아 빠르게 연산할 수 있어 실전에서 매우 유용합니다.

## 5. 신경 스타일 전이 (Neural Style Transfer)

콘텐츠(Content) 이미지와 스타일(Style) 이미지를 조합하여 새로운 예술적 이미지를 생성하는 기술입니다.

* **Content ($C$):** 담고 싶은 내용물 (예: 내 방 사진)
* **Style ($S$):** 입히고 싶은 화가의 화풍 (예: 반 고흐의 별이 빛나는 밤)
* **Generated Image ($G$):** 최종적으로 생성될 전이 이미지

### 비용 함수 (Cost Function)

기존 딥러닝과 달리, 신경 스타일 전이에서는 **모델의 가중치($W, b$)를 학습시키는 것이 아니라 무작위 노이즈 이미지 $G$의 픽셀 값 자체를 업데이트**합니다. 이를 평가하는 전체 비용 함수는 다음과 같습니다.

$$J(G) = \alpha J_{\text{content}}(C, G) + \beta J_{\text{style}}(S, G)$$

* $\alpha, \beta$: 콘텐츠와 스타일 중 어느 쪽에 더 가중치를 둘지 결정하는 하이버파라미터입니다.

## 6. 심층 신경망이 학습하는 것 (What are CNN layers really learning?)

스타일 전이의 비용 함수를 이해하기 위해, CNN의 깊은 레이어들이 시각적으로 무엇을 감지하는지 시각화하는 연구(Zeiler & Fergus)를 배웁니다.

* **얕은 레이어(Layer 1~2):** 선, 모서리, 단순한 질감, 색상 배치 등 아주 기본적인 저수준 특징을 감지합니다.
* **중간 레이어(Layer 3):** 원, 질감의 조합, 단순한 사물의 형태(자동차 바퀴, 사람 눈 등)를 인지하기 시작합니다.
* **깊은 레이어(Layer 4~5):** 고차원적인 복합 개념(개, 고양이, 부엉이의 얼굴, 다리, 특정 사물 전체 클래스)을 명확하게 포착합니다.

## 7. 콘텐츠 및 스타일 비용 함수 정밀 분석

### ① 콘텐츠 비용 함수 ($J_{\text{content}}$)

* 너무 얕지도 깊지도 않은 중간~후반부의 특정 레이어 $l$을 선택합니다. (너무 얕으면 픽셀 단위로 똑같아지려 하고, 너무 깊으면 형태가 너무 자유로워지기 때문)
* 콘텐츠 이미지 $C$와 생성 이미지 $G$를 VGG와 같은 사전 학습된 네트워크에 통과시켜 레이어 $l$의 활성화 값($a^{[l](C)}, a^{[l](G)}$)을 얻습니다.
* 두 활성화 값 행렬의 차이를 제곱하여 더한 값(L2 Norm)이 콘텐츠 비용이 됩니다.

### ② 스타일 비용 함수 ($J_{\text{style}}$)

스타일이란 이미지 전반에 걸쳐 나타나는 "특징들의 상관관계(Correlation)"로 정의할 수 있습니다. 예를 들어, '빨간색 격자 무늬'와 '거친 질감'이 이미지 전반에 걸쳐 얼마나 동시에 자주 등장하는지를 포착하는 것입니다.

* **그램 행렬 (Gram Matrix, $G^{[l]}$):** 레이어 $l$에서 채널 $i$의 특징 맵과 채널 $j$의 특징 맵이 공간적으로 얼마나 같이 활성화되었는지 내적(Dot product)을 통해 상관관계를 구한 행렬입니다.
* **연산:** 스타일 이미지 $S$의 그람 행렬 $A^{[l]}$과 생성 이미지 $G$의 그람 행렬 $B^{[l]}$을 구한 뒤, 이 두 행렬의 차이를 최소화하도록 유도합니다.
* 실전에서는 풍부한 화풍 전이를 위해 단 하나의 레이어가 아니라 **여러 레이어(Layer 1부터 5까지 전부)의 스타일 비용을 모두 더해서** 사용합니다.

## 8. 1D 및 3D 데이터로의 확장 (1D and 3D Generalizations)

합성곱은 2D 이미지에만 국한되지 않고 시계열 데이터나 의료 영상 등으로 유연하게 확장될 수 있음을 끝으로 배웁니다.

* **1D 합성곱 (1D Convolution):** 심전도(EKG) 신호, 소리(Audio), 텍스트 등 가로 축(시간 축)으로만 흘러가는 데이터에 필터를 슬라이딩합니다. ($14 \times 1$ 데이터에 $5 \times 1$ 필터를 가하면 $10 \times 1$ 출력이 됨)
* **3D 합성곱 (3D Convolution):** MRI, CT 스캔과 같은 의료 영상 데이터나 비디오(가로 $\times$ 세로 $\times$ 시간 프레임) 데이터를 다룰 때 사용합니다. 필터 자체가 3D 큐브 형태($f \times f \times f$)가 되어 공간의 깊이 방향으로도 슬라이딩하며 입체적인 특징을 추출합니다.
