# < Decision Tree Learning >

## 1. 불순도 측정
- 데이터 집합이 얼마나 불순한 지를 "엔트로피"를 이용해 측정한다.
- "지니 불순도" 역시 사용한다.

## 2. 정보 이득
- 특정 특징을 기준으로 분할 했을때 줄어드는 불순도의 양.
- **분할 기준 선택:** 여러 특징 중 **정보 이득(엔트로피 감소량)이 가장 큰 특징**을 분할 기준으로 선택하여 데이터의 순도를 가장 높이는 방향으로 트리를 생성합니다.



# < Tree Ensembles > 
- 단일 의사결정나무(Single Decision Tree)는 **데이터의 작은 변화에도 매우 민감하게 반응(Sensitive)한다는 약점**이 있습니다.
- 그래서 트리 앙상블 사용.
-  트리 앙상블의 동작 원리 (다수결 투표)
- 여러 개의 서로 다른 의사결정나무를 만들고, 이들의 예측 결과를 모아 다수결 투표(Majority Vote)로 최종 결과를 결정합니다.
## 1. Bagged Decision Trees 알고리즘
- 복원 추출(Sampling with replacement)을 활용해 여러 개의 의사결정나무를 만드는 앙상블 기법입니다.
- 복원 추출로 **데이터만 무작위**로 바꿔가며 여러 트리 생성

## 2. Random Forest 알고리즘
-  무작위 특성 선택 추가
- 복원 추출(**데이터 무작위**) + 노드 분할 시 특성도 무작위(k=n)로 골라 트리 다양성 극대화

## 3. Boosting 알고리즘
- 부스팅은 이전 트리가 **오답을 낸 "어려운 데이터"에 집중하여 다음 트리를 순차적으로 학습**시키는 기법입니다.


## 4. XG Boost
- XGBoost는 매번 데이터를 복원 추출하지 않고, 각 학습 데이터에 가중치(Weight)를 다르게 부여하는 방식을 사용해 연산 속도를 대폭 향상시켰습니다.
