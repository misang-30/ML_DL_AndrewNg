## 1.Linear Regression (선형 회귀)

### 1). 가설 함수 설정
- f(x) = wx + b
### 2). 비용 함수 설정
- 평균 제곱 오차 사용 (MSE)
- 오차를 비용 함수로 가공한다.


$$\text{Error}^{(i)} = f_{w,b}(x^{(i)}) - y^{(i)} = \hat{y}^{(i)} - y^{(i)}$$

$$J(w,b) = \frac{1}{2m} \sum_{i=1}^{m} \left( f_{w,b}(x^{(i)}) - y^{(i)} \right)^2$$

### 3). 경사 하강법으로 파라미터 업데이트
$$w \leftarrow w - \alpha \frac{\partial J}{\partial w}$$
$$b \leftarrow b - \alpha \frac{\partial J}{\partial b}$$

## 2. Polynomial Regression (다항 회귀)

### 0). 주의 사항
- 다항 회귀에서 반드시 주의할 점: 차수(Degree, $n$) 선택

- **차수가 너무 낮으면 ($n=1$):** 데이터를 충분히 설명하지 못하는 과소적합(Underfitting)이 발생합니다.
    
- **차수가 너무 높으면 ($n=10$ 이상):** 노이즈까지 지나치게 학습하여 과대적합(Overfitting)이 발생합니다 (지그재그 형태로 데이터 포인트에만 맞춰짐).
    

- 따라서 적절한 차수 $n$을 선택하는 것이 다항 회귀의 핵심입니다.


#### 1). 가설 함수 설정

- $n$차 다항식으로 설정합니다.

$$f_{\mathbf{w},b}(x) = w_1 x + w_2 x^2 + w_3 x^3 + \dots + w_n x^n + b$$

### 2). 비용 함수 설정
- 평균 제곱 오차(MSE)를 그대로 사용합니다.

$$J(\mathbf{w},b) = \frac{1}{2m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right)^2$$

#### 3) 경사 하강법으로 파라미터 업데이트

- 특성(Feature)이 늘어났을 뿐, 각 가중치 $w_j$와 편향 $b$를 업데이트하는 메커니즘은 선형 회귀와 동일합니다.

- **가중치($w_j$) 업데이트:**
    
    $$w_j \leftarrow w_j - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right) (x^{(i)})^j$$
    
- **편향($b$) 업데이트:**
    
    $$b \leftarrow b - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right)$$

## 3. Regularized Linear Models
- Ridge / LASSO / ElasticNet

### 0). 개념
 - 모델이 너무 복잡해져서 훈련 데이터에만 지나치게 맞춰지는 과대 적합을 막기 위해 규제를 추가한 선형 회귀의 변형 모델


1. **기본값:** 데이터 특성이 전반적으로 다 의미가 있다면 **Ridge**가 가장 무난하고 성능이 좋습니다. 
2. **변수 솎아내기:** 특성이 수백 개인데 진짜 중요한 몇 개만 추려내고 싶다면 **LASSO**를 씁니다.
3. **특성 수가 많고 서로 얽혀있을 때:** 특성 개수가 데이터 수보다 많거나 상관관계가 높은 특성이 많다면 **ElasticNet**이 가장 안정적입니다.

| **구분**    | **Ridge (릿지)**      | **LASSO (라쏘)**                  | **ElasticNet (엘라스틱넷)** |
| --------- | ------------------- | ------------------------------- | ---------------------- |
| **규제 방식** | **L2 규제** (가중치 제곱합) | **L1 규제** (가중치 절댓값합)            | **L1 + L2 규제 혼합**      |
| **주요 특징** | 가중치를 **0에 가깝게** 줄임  | 불필요한 가중치를 **완전히 0**으로 만듦        | 둘의 장점을 짬뽕함             |
| **핵심 효과** | 모든 특성을 살리면서 안정화     | **특성 선택(Feature Selection)** 효과 | 상관관계 높은 특성도 잘 처리함      |

### 1). Ridge Regression
- **1) 가설 함수**


$$f_{\mathbf{w},b}(x) = \mathbf{w}^T x + b$$

- **2) 비용 함수**
- MSE에 **가중치 제곱합($\text{L2 Norm}$)** 항을 추가합니다. ($\alpha$ 또는 $\lambda$는 규제 강도)

$$J(\mathbf{w},b) = \frac{1}{2m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right)^2 + \lambda \sum_{j=1}^{n} w_j^2$$
- **3) 경사 하강법 (가중치 업데이트)**
- 기존 MSE 미분값에 가중치 자체($w_j$)가 추가로 차감되어 **가중치를 지속적으로 줄여주는 효과**가 나타납니다.

$$w_j \leftarrow w_j(1 - \alpha \frac{\lambda}{m}) - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right) x_j^{(i)}$$



### 2). LASSO Regression

- **1) 가설 함수**


$$f_{\mathbf{w},b}(x) = \mathbf{w}^T x + b$$

- **2) 비용 함수**

- MSE에 **가중치 절댓값 합($\text{L1 Norm}$)** 항을 추가합니다.

$$J(\mathbf{w},b) = \frac{1}{2m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right)^2 + \lambda \sum_{j=1}^{n} \vert{}w_j\vert{}$$

- **3) 경사 하강법 (가중치 업데이트)**

- $\vert{}w_j\vert{}$는 $w=0$에서 미분이 불가능하므로, 부호 함수($\text{sign}$)를 사용하는 **서브그라디언트(Subgradient)** 방식을 적용합니다.

$$w_j \leftarrow w_j - \alpha \frac{\lambda}{m} \cdot \text{sign}(w_j) - \alpha \frac{1}{m} \sum_{i=1}^{m} \left( f_{\mathbf{w},b}(x^{(i)}) - y^{(i)} \right) x_j^{(i)}$$

- (단, $\text{sign}(w_j)$는 $w_j > 0$이면 $1$, $w_j < 0$이면 $-1$)

### 3). ElasticNet
- **1) 가설 함수**


$$f_{\mathbf{w},b}(x) = \mathbf{w}^T x + b$$

- **2) 비용 함수**
- L1 비율을 조절하는 혼합 파라미터 $r \in [0, 1]$을 사용합니다. ($r=1$이면 LASSO, $r=0$이면 Ridge)

$$J(\mathbf{w},b) = \text{MSE} + r \lambda \sum_{j=1}^{n} \vert{}w_j\vert{} + \frac{1-r}{2} \lambda \sum_{j=1}^{n} w_j^2$$

- **3) 파라미터 업데이트**
- L1의 서브그라디언트 항과 L2의 가중치 수축 항이 결합되어 업데이트됩니다.
